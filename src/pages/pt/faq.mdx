# Perguntas frequentes

## Qual é a diferença entre os dois conjuntos de modelos Claude na Aiberm?

A Aiberm oferece dois conjuntos de modelos Claude para casos de uso diferentes:

- **Modelos com prefixo `claude-`**: Disponíveis com 81% de desconto, mais adequados para cenários de programação. O Claude Code oferece suporte por padrão aos modelos com prefixo `claude-`.
- **Modelos com prefixo `anthropic/`**: Encaminhados pela AWS, com cerca de 28% de desconto em relação ao preço oficial.

## Os modelos da Aiberm oferecem suporte a cache?

Sim, todos os modelos Claude da Aiberm oferecem suporte a cache de prompt. O cache foi otimizado para altas taxas de acerto. Quando o cache é atingido, o preço é multiplicado por 0,1. Outros modelos também oferecem suporte a cache.


## Como obter uma fatura?

- **Fatura self-service**: [https://meiguo.app/invoice](https://meiguo.app/invoice)
- Faturas por **transferência bancária corporativa** estão disponíveis — entre em contato com o administrador do grupo @Folyd
- **Transferências não corporativas** exigem um mínimo de US$ 500 para Fapiao chinesa. Abaixo de US$ 500, aplica-se uma taxa adicional de 8% de imposto.
