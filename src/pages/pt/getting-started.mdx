# Início rápido

A Aiberm oferece uma API unificada que dá acesso a centenas de modelos de IA por um único endpoint. Comece em minutos com nosso processo simples de integração.

<Callout client:load type="tip">
Procurando informações sobre modelos gratuitos e limites de taxa? Consulte as Perguntas frequentes.
</Callout>

## Usar o SDK da OpenAI

A forma mais fácil é usar o SDK oficial da OpenAI: basta alterar o base_url para começar a usá-lo.

<CodeExample
  client:load
  examples={[
    {
      key: 'python',
      label: 'Python',
      code: `from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key-here",
    base_url="https://aiberm.com/v1"
)

response = client.chat.completions.create(
    model="google/gemini-2.5-flash",
    messages=[
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)`
    },
    {
      key: 'typescript',
      label: 'TypeScript',
      code: `import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: 'sk-your-api-key-here',
  baseURL: 'https://aiberm.com/v1'
});

const response = await openai.chat.completions.create({
  model: 'google/gemini-2.5-flash',
  messages: [
    { role: 'user', content: 'Hello!' }
  ]
});

console.log(response.choices[0].message.content);`
    }
  ]}
/>

## Usar a API da Aiberm diretamente

Você pode usar solicitações HTTP para chamar a API diretamente.

<Callout client:load type="info">
Use nosso Request Builder interativo para gerar solicitações à API.
</Callout>

<CodeExample
  client:load
  examples={[
    {
      key: 'python',
      label: 'Python',
      code: `import requests

response = requests.post(
    "https://aiberm.com/v1/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={
        "model": "google/gemini-2.5-flash",
        "messages": [
            {"role": "user", "content": "Hello!"}
        ]
    }
)

print(response.json())`
    },
    {
      key: 'typescript',
      label: 'TypeScript',
      code: `const response = await fetch('https://aiberm.com/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    model: 'google/gemini-2.5-flash',
    messages: [{ role: 'user', content: 'Hello!' }]
  })
});

const data = await response.json();
console.log(data);`
    },
    {
      key: 'curl',
      label: 'Curl',
      code: `curl https://aiberm.com/v1/chat/completions \\
  -H "Content-Type: application/json" \\
  -H "Authorization: Bearer YOUR_API_KEY" \\
  -d '{
    "model": "google/gemini-2.5-flash",
    "messages": [
      {"role": "user", "content": "Hello!"}
    ]
  }'`
    }
  ]}
/>
