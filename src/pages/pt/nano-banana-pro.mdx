# NanoBanana Pro

O NanoBanana Pro é o serviço de geração de imagens do Gemini. Ele oferece suporte a várias proporções (1:1, 16:9, 9:16 etc.) e resoluções (1K, 2K, 4K). Todas as resoluções compartilham o mesmo preço; 4K é mais lento para gerar e não é recomendado. Consulte [Preços](/pricing?tab=gemini).

**Endpoint**: `POST https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent`

**Pontos-chave**: Envie a descrição da imagem no corpo da solicitação em `contents`; defina `responseModalities` e `imageConfig` (proporção, resolução) em `generationConfig`. A imagem gerada está em `candidates[0].content.parts` como `inline_data`.

## Exemplo de código

O Python usa snake_case (por exemplo, `response_modalities`); REST/cURL usa camelCase (por exemplo, `responseModalities`). Eles têm o mesmo significado.

### Parâmetros de imagem no cURL

Abaixo estão os nomes dos parâmetros (camelCase) para cURL; use snake_case no Python (por exemplo, `aspectRatio` → `aspect_ratio`).

**imageConfig** (`generationConfig.imageConfig` ou SDK `ImageConfig`):

- **aspectRatio** `string` — `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`
- **imageSize** `string` — `1K`, `2K`, `4K` (somente gemini-3-pro-image-preview)

**Outros campos comuns de generationConfig:**

- **responseModalities** `string[]` — `["IMAGE"]` ou `["TEXT", "IMAGE"]`
- **temperature** `number` — 0–2, valores mais altos = mais aleatório
- **topP** `number` — 0–1, diversidade
- **maxOutputTokens** `number` — por exemplo, 8192
- **systemInstruction** `object` — por exemplo, `{"parts": [{"text": "..."}]}`
- **tools** `array` — por exemplo, `[{"google_search": {}}]`

## Ativar o Google Search

Somente a API no estilo Gemini oferece suporte ao Google Search. Passe `tools` na configuração; o modelo usará informações da web em tempo real quando necessário.

**Não recomendado por padrão:** Adiciona latência e custo; desnecessário para uso somente de imagens. Desative se você não precisar de busca.

**Python (SDK):**

```python
config = types.GenerateContentConfig(
    # ... other params like response_modalities, image_config
    tools=[{"google_search": {}}]
)
response = client.models.generate_content(model=model, contents=[prompt], config=config)
```

**cURL (REST):**

Adicione `tools` no nível superior do corpo da solicitação:

```bash
curl -X POST "https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "Your question"}]}],
    "generationConfig": { ... },
    "tools": [{"google_search": {}}]
  }'
```

## Perguntas frequentes

- **Nenhuma imagem na resposta:** Certifique-se de que o modelo é `gemini-3-pro-image-preview` e de que o prompt é uma descrição clara da imagem.
- **Erro de decodificação:** Use apenas a string base64 após `data:image/...;base64,` e remova as quebras de linha antes de decodificar.
