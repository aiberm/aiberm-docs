# Configuração do Hermes Agent

Este guia descreve como configurar o [Hermes Agent](https://hermes-agent.nousresearch.com/) para usar a Aiberm como provedor de modelos. O Hermes Agent é um agente de IA de código aberto desenvolvido pela Nous Research que roda no terminal e se integra a plataformas de mensagens, incluindo Telegram, Discord, Slack, WhatsApp e Signal.

Como a Aiberm expõe uma API `/v1` compatível com a OpenAI, ela pode ser registrada como um provedor personalizado no Hermes Agent sem instalar nenhum plugin nem modificar o código-fonte. Depois de configurada, uma única chave de API dá acesso a todos os modelos disponíveis na Aiberm, incluindo Claude, GPT, Gemini, DeepSeek, Kimi, MiniMax, GLM e Grok.

## Pré-requisitos

- Uma conta Aiberm ([Cadastre-se](https://aiberm.com/register))
- Uma chave de API da Aiberm ([Obtenha sua chave](https://aiberm.com/console/token))
- Hermes Agent instalado — consulte o [guia oficial de instalação](https://hermes-agent.nousresearch.com/docs/getting-started/)

Instalação rápida (Linux / macOS / WSL2):

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

## Configurar a Aiberm como provedor

O Hermes Agent armazena sua configuração em `~/.hermes/config.yaml`. Abra o arquivo e adicione uma entrada `aiberm` na seção `providers:`.

> **Se você não se sente confortável com editores de linha de comando como o Vim**, pode abrir o arquivo de configuração usando o editor integrado do seu sistema operacional:
>
> - **macOS**: Abra o **Finder**, pressione `Shift + Command + G`, digite `~/.hermes` na caixa de diálogo que aparecer e pressione Return. Localize o arquivo `config.yaml`, clique com o botão direito e selecione **Abrir com → TextEdit**.
> - **Windows**: Abra o **Explorador de Arquivos**, digite `%USERPROFILE%\.hermes` na barra de endereço e pressione Enter. Clique com o botão direito em `config.yaml` e selecione **Abrir com → Bloco de Notas**.
>
> Depois de editar, lembre-se de **salvar o arquivo** (`Command + S` no macOS, `Ctrl + S` no Windows) e, em seguida, prossiga para a etapa de reinicialização descrita abaixo.

### Referência dos campos

| Campo | Obrigatório | Descrição |
|-------|----------|-------------|
| `base_url` | Sim | Endpoint compatível com a OpenAI da Aiberm. Defina como `https://aiberm.com/v1`. |
| `api_key` | Sim | Sua chave de API da Aiberm, disponível no [console](https://aiberm.com/console/token). |
| `type` | Sim | Tipo de protocolo. Defina como `openai` — a Aiberm está em conformidade com a especificação OpenAI Chat Completions. |
| `default_model` | Sim | O modelo usado quando nenhum modelo explícito é especificado. |
| `models` | Recomendado | A lista de modelos exibida no seletor `/model`. O Hermes mostra apenas as entradas presentes nesta lista (mais `default_model`). Se for omitida, o seletor exibe um único botão. |

A seção de nível superior `model:` designa o provedor ativo e o modelo padrão. Se você estava usando outro provedor, defina `provider:` como `aiberm` e defina `default:` como qualquer modelo listado no bloco `models:`.

## Uso

Após atualizar a configuração, reinicie o Hermes (CLI: saia e execute novamente `hermes`; gateway: `hermes gateway restart`).

**No terminal (CLI):**

```
/model
```

O Hermes abre um seletor interativo de modelos. Selecione **Aiberm** e, em seguida, escolha o modelo desejado. Você também pode trocar diretamente:

```
/model claude-opus-4-7
/model gpt-5.4 --global
```

Adicionar `--global` persiste a alteração em `config.yaml`; omiti-lo aplica a alteração apenas à sessão atual.

**No Telegram, Discord, Slack ou WhatsApp:**

Envie `/model` para o seu bot. Ele retorna um teclado inline listando todos os provedores para os quais as credenciais estão configuradas. Selecione **Aiberm** para ver a lista paginada de modelos (8 por página, com navegação Prev / Next) e, em seguida, toque em um modelo para trocar.

![Seletor /model do Telegram mostrando a lista paginada de modelos da Aiberm](/docs/hermes-model-picker.png)

## Ver o catálogo completo de modelos

A lista `models:` acima é um subconjunto selecionado. Para ver todos os modelos atualmente servidos pela Aiberm, consulte a API diretamente:

```bash
curl -H "Authorization: Bearer sk-your-aiberm-api-key" \
     https://aiberm.com/v1/models | jq -r '.data[].id'
```

Adicione quaisquer IDs de modelo que você queira usar ao seu bloco `models:` e reinicie o Hermes. Eles aparecerão então no seletor `/model`.

## Usar variáveis de ambiente (opcional)

Se preferir não armazenar a chave de API em `config.yaml`, você pode lê-la de uma variável de ambiente. Defina:

```bash
export AIBERM_API_KEY=sk-your-aiberm-api-key
```

Em seguida, referencie-a em `config.yaml` via `key_env`:

```yaml
providers:
  aiberm:
    base_url: https://aiberm.com/v1
    key_env: AIBERM_API_KEY
    type: openai
    default_model: claude-sonnet-4-6
```

## Solução de problemas

### `/model` mostra apenas um único botão para a Aiberm

O bloco `providers.aiberm` está sem a lista `models:`. O seletor do Hermes só pagina quando mais de 8 modelos estão configurados. Adicione a lista selecionada mostrada acima e reinicie o Hermes.

### 401 Unauthorized

- Verifique a chave de API no [console da Aiberm](https://aiberm.com/console/token).
- Confirme se a chave está em `providers.aiberm.api_key`, e não no nível superior da configuração.

### Modelo não encontrado

O catálogo de modelos da Aiberm evolui com o tempo; um modelo que você tinha listado pode ter sido renomeado ou descontinuado. Consulte `/v1/models` novamente (veja acima) e atualize sua lista `models:` de acordo.

### Como verificar se a configuração foi carregada

```bash
hermes doctor
```

Este comando imprime um relatório de diagnóstico que inclui o provedor e o modelo atualmente ativos.
