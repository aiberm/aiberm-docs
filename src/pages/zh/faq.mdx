# 常见问题


## Aiberm 在中国大陆需要代理才能连接吗？

Aiberm 不需要代理就能连接。

## Aiberm 的两套 Claude 模型有什么区别？

Aiberm 提供两套 Claude 模型，适用于不同的使用场景：

- **`claude-` 开头的模型**：1.9 折优惠价，最适合 Coding 场景。Claude Code 默认支持 `claude-` 开头的模型。
- **`anthropic/` 开头的模型**：走 AWS 通道，官方 7.2 折左右。

## Aiberm 的模型支持缓存吗？

支持的，Aiberm Claude 全系列支持缓存，缓存命中有经过调优，命中缓存后价格乘以 0.1，其他模型也同样支持缓存。

## Aiberm 是什么汇率？

Aiberm 跟其他平台不一样，不玩汇率的游戏，充值是正常的汇率 7，消费的时候是折扣价。

## 如何开具 Invoice / 发票？

- **自助开 Invoice**：[https://meiguo.app/invoice](https://meiguo.app/invoice)
- **对公转账**可开发票，请联系群主 @Folyd
- **非对公转账**需满 $500 才可开发票，低于 $500 需补 8% 税点
