# 图像

aiberm 目前支持以下图像相关能力，请点击对应页面查看使用说明与接入方式。

## 图像生成

**[GPT Image 2](/docs/zh/gpt-image-2/)** — 通过 OpenAI 兼容图像接口生成与编辑图片。

**[NanoBanana Pro](/docs/zh/nano-banana-pro/)** — 根据文本描述生成图像。

## 图像编辑

**[GPT Image 2](/docs/zh/gpt-image-2/)** — 支持参考图、蒙版编辑与流式局部图片。

**[NanoBananaPro Edit](/docs/zh/nano-banana-pro-edit/)** — 在已有图像基础上进行编辑与修改。
