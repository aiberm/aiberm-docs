# Aiberm Skill

[aiberm-skill](https://github.com/aiberm/aiberm-skill) 教会编程 Agent 读取你自己的 Aiberm 账户。装好之后，你可以直接问 Claude Code、Codex、Grok Build 或其他 Agent：“我的 Aiberm 还剩多少余额？”Agent 会自己调用 Aiberm 的接口，用大白话回答你。

这个 Skill 能查余额、模型、价格、API 令牌、使用日志和充值记录，还能创建、修改、启用、禁用和删除你的 API 令牌，每次改动前都会先征求你的同意。

<Callout client:load type="info">
Skill 就是一个包含 `SKILL.md` 文件的文件夹。当你的问题和 Skill 描述对得上时，Agent 会读这个文件，然后自己运行 `curl`。没有后台进程，不需要编译，也不用一直开着什么。
</Callout>

## 前置条件

- 一个 Aiberm 账户（[注册](https://aiberm.com/register)）
- 一个支持 Skill 的 Agent，例如 [Claude Code](/docs/zh/claude-code/)、[Codex](/docs/zh/codex/) 或 [Grok Build](https://x.ai/build)
- `git`、`curl` 和兼容 bash 的 shell。macOS 和 Linux 一般都自带；Windows 上的 Claude Code 使用 Git Bash。

## 1. 获取用户 ID 和系统访问令牌

Skill 需要两个值，都在 [个人设置](https://aiberm.com/console/personal) 页面：

| 值 | 位置 |
| --- | --- |
| 用户 ID | 页面顶部的信息栏，显示为 `ID: 123` |
| 系统访问令牌 | **安全设置** 标签页 → **系统访问令牌** → **生成令牌** |

Aiberm 的每个账户接口都会同时校验这两个值，而且 ID 必须属于令牌所在的账户。

<Callout client:load type="warning">
系统访问令牌**不是** API Key（`sk-...`）。它相当于你的控制台登录：拿到它的人能做你在控制台里能做的一切事情，请妥善保管。点 **重新生成** 会替换掉旧令牌，还在用旧令牌的地方会立即失效。
</Callout>

## 2. 安装 Skill

把下面这段提示词发给 Claude Code、Codex、Grok Build 或其他 Agent，让它自己安装：

```text
从 https://github.com/aiberm/aiberm-skill 安装 Aiberm Skill：把仓库里的 skills/aiberm 文件夹复制到你加载 Skill 的目录。
```

装好后开一个新会话。以后要更新，再发一次同样的提示词即可。

## 3. 设置两个环境变量

Agent 从自己的环境变量里读取这两个值，所以要在启动 Agent 之前设置好。

**macOS / Linux**：把下面两行加到 `~/.zshrc` 或 `~/.bashrc`，然后打开一个新终端：

```bash
export AIBERM_ACCESS_TOKEN="你的系统访问令牌"
export AIBERM_USER_ID="123"
```

**Windows（PowerShell）**：运行下面的命令，然后打开一个新终端：

```powershell
setx AIBERM_ACCESS_TOKEN "你的系统访问令牌"
setx AIBERM_USER_ID "123"
```

<Callout client:load type="tip">
如果只用 Claude Code，也可以把这两个变量写进 `~/.claude/settings.json` 的 `env` 块。
</Callout>

在交给 Agent 之前，可以先请求一次个人资料来检查这两个值。`data.quota` 除以 500000 就是以美元计的剩余余额。

```bash
curl -sS "https://aiberm.com/api/user/self" \
  -H "Authorization: Bearer $AIBERM_ACCESS_TOKEN" \
  -H "New-Api-User: $AIBERM_USER_ID"
```

## 4. 向 Agent 提问

开一个新的 Agent 会话，用你自己的话问就行：

- “我的 Aiberm 还剩多少余额？”
- “我昨天在 Aiberm 上花了多少钱？按模型分一下。”
- “列出我的 Aiberm API 令牌，以及每个还剩多少额度。”
- “`claude-sonnet-5-5` 在 Aiberm 上每 100 万 token 多少钱？”
- “这周我在 Aiberm 上用得最多的是哪些模型？”
- “看看我最近的 Aiberm 充值记录。”
- “帮我在 Aiberm 创建一个叫 `my-app` 的 API Key，额度上限 5 美元。”
- “把我的 Aiberm 令牌 `old-test` 禁用掉。”

也可以直接调用这个 Skill：Claude Code 和 Grok Build 里输入 `/aiberm`，Codex 里输入 `$aiberm`。

| 你问的内容 | Skill 读取的接口 |
| --- | --- |
| 余额和累计消费 | `GET /api/user/self` |
| 可以调用的模型 | `GET /api/user/models` |
| 模型价格 | `GET /api/pricing` |
| API 令牌 | `GET /api/token/` |
| 使用日志 | `GET /api/log/self` |
| 用量汇总 | `GET /api/log/self/stat` |
| 按小时和模型的用量 | `GET /api/data/self` |
| 充值记录 | `GET /api/user/topup/self` |
| 创建、修改或删除 API 令牌 | `POST`、`PUT` 或 `DELETE /api/token/` |

金额按 500000 额度 = 1 美元换算成美元。价格就是你的账户实际支付的价格。

### 创建和修改 API 令牌

- 每次创建、修改、启用、禁用或删除之前，Agent 都会先告诉你要提交的内容，等你确认后再执行。
- 如果你没有特别要求，新令牌和控制台的默认设置一样：无限额度、永不过期。你也可以指定额度上限、过期时间或允许使用的模型。
- 创建完成后，Agent 会把完整的 Key 显示一次，复制到你的应用或配置里即可。
- 删除令牌无法撤销，正在使用这个 Key 的应用会立即失效。

## Skill 不会做的事

- 除了 API 令牌，不修改任何东西：不付款，不兑换充值码，不改账户资料。这些请到 [控制台](https://aiberm.com/console) 操作。
- 不重置你的系统访问令牌。Skill 明确要求 Agent 永远不要调用那个接口。
- 不泄露已有令牌的完整 API Key。令牌列表里包含完整的 Key，Agent 只会显示打码后的形式，例如 `sk-abcd****wxyz`。需要完整 Key 时，请到 [令牌管理](https://aiberm.com/console/token) 复制。唯一的例外是 Agent 刚刚为你创建的令牌。

<Callout client:load type="warning">
这些规则是写给 Agent 的指令，不是技术上的锁。令牌本身拥有你控制台登录的全部权限，只在你信任的 Agent 和机器上使用。如果泄露了，到个人设置里点 **重新生成**。
</Callout>

## 常见问题排查

| 现象 | 处理方法 |
| --- | --- |
| Agent 说缺少环境变量 | 把两个变量都设置好，打开新终端，再开一个新的 Agent 会话。 |
| `未提供 New-Api-User` | 没有设置 `AIBERM_USER_ID`。 |
| `New-Api-User 与登录用户不匹配` | `AIBERM_USER_ID` 不是令牌所属账户的 ID。请在同一个账户的个人设置里复制 ID。 |
| `access token 无效` | 令牌填错了，或者已经重新生成过。生成一个新令牌并更新 `AIBERM_ACCESS_TOKEN`。 |
| Agent 没有用这个 Skill | 确认文件位于 `~/.claude/skills/aiberm/SKILL.md`、`~/.agents/skills/aiberm/SKILL.md` 或 `~/.grok/skills/aiberm/SKILL.md`，然后开一个新会话。也可以直接调用：Claude Code 和 Grok Build 里输入 `/aiberm`，Codex 里输入 `$aiberm`。 |
| `时间跨度不能超过 1 个月` | 按小时的用量每次最多查询 30 天，请缩短时间范围。 |

Skill 源码和完整的接口列表在 [aiberm-skill 仓库](https://github.com/aiberm/aiberm-skill)。模型接口本身的报错请参阅 [错误处理](/docs/zh/error-handling/)。
