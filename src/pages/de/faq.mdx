# FAQ

## Worin unterscheiden sich die beiden Claude-Modellreihen auf Aiberm?

Aiberm bietet zwei Claude-Modellreihen für unterschiedliche Einsatzzwecke:

- **Modelle mit Präfix `claude-`**: mit 81 % Rabatt verfügbar und besonders für Coding geeignet. Claude Code unterstützt standardmäßig Modelle mit Präfix `claude-`.
- **Modelle mit Präfix `anthropic/`**: werden über AWS geroutet, etwa 28 % unter dem offiziellen Preis.

## Unterstützen Aiberm-Modelle Caching?

Ja, alle Claude-Modelle von Aiberm unterstützen Prompt Caching. Das Caching ist auf hohe Trefferquoten optimiert. Bei einem Cache-Treffer wird der Preis mit 0.1 multipliziert. Andere Modelle unterstützen ebenfalls Caching.

## Wie erhalte ich eine Rechnung?

- **Self-Service-Rechnung**: [https://meiguo.app/invoice](https://meiguo.app/invoice)
- Rechnungen bei **Firmenüberweisung** sind verfügbar — kontaktieren Sie den Gruppenadmin @Folyd
- Bei **nicht-geschäftlichen Überweisungen** gilt ein Minimum von 500 $ für eine chinesische Fapiao. Unter 500 $ fällt ein zusätzlicher Steueraufschlag von 8 % an.
