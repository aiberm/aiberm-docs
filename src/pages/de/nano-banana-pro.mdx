# NanoBanana Pro

NanoBanana Pro ist der Bildgenerierungsdienst von Gemini. Es unterstützt mehrere Seitenverhältnisse (1:1, 16:9, 9:16 usw.) und Auflösungen (1K, 2K, 4K). Alle Auflösungen haben denselben Preis; 4K wird langsamer erzeugt und wird nicht empfohlen. Siehe [Preise](/pricing?tab=gemini).

**Endpunkt**: `POST https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent`

**Wichtige Punkte**: Senden Sie die Bildbeschreibung im Anfragekörper unter `contents`; setzen Sie `responseModalities` und `imageConfig` (Seitenverhältnis, Auflösung) in `generationConfig`. Das erzeugte Bild liegt in `candidates[0].content.parts` als `inline_data`.

## Beispielcode

Python verwendet snake_case (z. B. `response_modalities`); REST/cURL verwendet camelCase (z. B. `responseModalities`). Die Bedeutung ist dieselbe.

### cURL-Bildparameter

Unten stehen die Parameternamen (camelCase) für cURL; in Python verwenden Sie snake_case (z. B. `aspectRatio` → `aspect_ratio`).

**imageConfig** (`generationConfig.imageConfig` oder SDK `ImageConfig`):

- **aspectRatio** `string` — `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`
- **imageSize** `string` — `1K`, `2K`, `4K` (nur gemini-3-pro-image-preview)

**Weitere gängige Felder von generationConfig:**

- **responseModalities** `string[]` — `["IMAGE"]` oder `["TEXT", "IMAGE"]`
- **temperature** `number` — 0–2, höher = zufälliger
- **topP** `number` — 0–1, Vielfalt
- **maxOutputTokens** `number` — z. B. 8192
- **systemInstruction** `object` — z. B. `{"parts": [{"text": "..."}]}`
- **tools** `array` — z. B. `[{"google_search": {}}]`

## Google Search aktivieren

Nur die Gemini-artige API unterstützt Google Search. Übergeben Sie `tools` in der Konfiguration; das Modell nutzt bei Bedarf Echtzeit-Webinformationen.

**Standardmäßig nicht empfohlen:** Erhöht Latenz und Kosten; für reine Bildnutzung unnötig. Deaktivieren Sie die Suche, wenn Sie sie nicht brauchen.

**Python (SDK):**

```python
config = types.GenerateContentConfig(
    # ... other params like response_modalities, image_config
    tools=[{"google_search": {}}]
)
response = client.models.generate_content(model=model, contents=[prompt], config=config)
```

**cURL (REST):**

Fügen Sie `tools` auf der obersten Ebene des Anfragekörpers hinzu:

```bash
curl -X POST "https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "Your question"}]}],
    "generationConfig": { ... },
    "tools": [{"google_search": {}}]
  }'
```

## FAQ

- **Kein Bild in der Antwort:** Stellen Sie sicher, dass das Modell `gemini-3-pro-image-preview` ist und die Eingabe eine klare Bildbeschreibung ist.
- **Dekodierungsfehler:** Verwenden Sie nur die Base64-Zeichenkette nach `data:image/...;base64,` und entfernen Sie Zeilenumbrüche vor dem Dekodieren.
