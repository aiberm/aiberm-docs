# Aiberm Skill

[aiberm-skill](https://github.com/aiberm/aiberm-skill) bringt einem Coding-Agenten bei, Ihr eigenes Aiberm-Konto auszulesen. Nach der Installation können Sie Claude Code, Codex, Grok Bot oder einen anderen Agenten fragen: „Wie viel Guthaben habe ich bei Aiberm noch?“ Der Agent ruft die Aiberm-API auf und antwortet in verständlicher Sprache.

Der Skill liest Ihr Guthaben, Ihre Modelle, Preise, API-Tokens, Nutzungsprotokolle und Aufladungen aus. Außerdem kann er Ihre API-Tokens erstellen, bearbeiten, aktivieren, deaktivieren und löschen und fragt vor jeder Änderung bei Ihnen nach.

<Callout client:load type="info">
Ein Skill ist ein Ordner mit einer Datei `SKILL.md`. Passt Ihre Frage zur Beschreibung des Skills, liest der Agent die Datei und führt `curl` selbst aus. Nichts läuft im Hintergrund, und es gibt nichts zu bauen oder dauerhaft laufen zu lassen.
</Callout>

## Voraussetzungen

- Ein Aiberm-Konto ([Registrieren](https://aiberm.com/register))
- Ein Agent, der Skills unterstützt, zum Beispiel [Claude Code](/docs/de/claude-code/), [Codex](/docs/de/codex/) oder [Grok Bot](https://docs.x.ai/grok-bot)
- `git`, `curl` und eine Bash-kompatible Shell. macOS und Linux bringen in der Regel alle drei mit. Unter Windows verwendet Claude Code Git Bash.

## 1. Benutzer-ID und System-Zugriffstoken abrufen

Der Skill braucht zwei Werte. Beide finden Sie unter [Persönliche Einstellungen](https://aiberm.com/console/personal):

| Wert | Wo Sie ihn finden |
| --- | --- |
| Benutzer-ID | In der Kopfzeile oben auf der Seite, angezeigt als `ID: 123` |
| System-Zugriffstoken | Tab **Sicherheitseinstellungen** → **System-Zugriffstoken** → **Token generieren** |

Aiberm prüft bei jeder Kontoanfrage beide Werte. Die ID muss zu dem Konto gehören, dem das Token gehört.

<Callout client:load type="warning">
Das System-Zugriffstoken ist **kein** API-Schlüssel (`sk-...`). Es wirkt wie Ihre Anmeldung in der Konsole: Wer es besitzt, kann in der Konsole alles tun, was Sie tun können. Halten Sie es geheim. Ein Klick auf **Neu generieren** ersetzt es, und alles, was noch das alte Token verwendet, funktioniert dann nicht mehr.
</Callout>

## 2. Skill installieren

Fügen Sie diesen Prompt in Claude Code, Codex, Grok Bot oder einen anderen Agenten ein und lassen Sie ihn den Skill installieren:

```text
Installiere den Aiberm Skill von https://github.com/aiberm/aiberm-skill: Kopiere den Ordner skills/aiberm daraus in den Ordner, aus dem du Skills lädst.
```

Wenn der Agent fertig ist, starten Sie eine neue Sitzung. Um den Skill später zu aktualisieren, senden Sie denselben Prompt erneut.

## 3. Die beiden Variablen setzen

Der Agent liest die Werte aus seiner Umgebung. Setzen Sie sie daher, bevor Sie ihn starten.

**macOS / Linux**: Fügen Sie diese Zeilen zu `~/.zshrc` oder `~/.bashrc` hinzu und öffnen Sie dann ein neues Terminal:

```bash
export AIBERM_ACCESS_TOKEN="ihr-system-zugriffstoken"
export AIBERM_USER_ID="123"
```

**Windows (PowerShell)**: Führen Sie die folgenden Befehle aus und öffnen Sie dann ein neues Terminal:

```powershell
setx AIBERM_ACCESS_TOKEN "ihr-system-zugriffstoken"
setx AIBERM_USER_ID "123"
```

<Callout client:load type="tip">
Nur für Claude Code: Sie können beide Variablen stattdessen auch in den `env`-Block von `~/.claude/settings.json` eintragen.
</Callout>

Um die Werte zu prüfen, bevor ein Agent ins Spiel kommt, rufen Sie Ihr Profil ab. `data.quota` geteilt durch 500000 ergibt Ihr Restguthaben in USD.

```bash
curl -sS "https://aiberm.com/api/user/self" \
  -H "Authorization: Bearer $AIBERM_ACCESS_TOKEN" \
  -H "New-Api-User: $AIBERM_USER_ID"
```

## 4. Den Agenten fragen

Starten Sie eine neue Agent-Sitzung und fragen Sie in Ihren eigenen Worten:

- „Wie viel Guthaben habe ich bei Aiberm noch?“
- „Wie viel habe ich gestern bei Aiberm ausgegeben, aufgeschlüsselt nach Modell?“
- „Zeig mir meine Aiberm-API-Tokens und wie viel Kontingent bei jedem noch übrig ist.“
- „Was kostet `claude-sonnet-5-5` pro 1M Tokens bei Aiberm?“
- „Welche Modelle habe ich diese Woche bei Aiberm am meisten genutzt?“
- „Zeig mir meine letzten Aufladungen bei Aiberm.“
- „Erstelle einen Aiberm-API-Schlüssel namens `my-app` mit einem Limit von 5 $.“
- „Deaktiviere mein Aiberm-Token `old-test`.“

Sie können den Skill auch direkt aufrufen: mit `/aiberm` in Claude Code und Grok Bot, mit `$aiberm` in Codex.

| Ihre Frage betrifft | Was der Skill abfragt |
| --- | --- |
| Guthaben und Gesamtausgaben | `GET /api/user/self` |
| Modelle, die Sie aufrufen können | `GET /api/user/models` |
| Modellpreise | `GET /api/pricing` |
| API-Tokens | `GET /api/token/` |
| Nutzungsprotokolle | `GET /api/log/self` |
| Nutzungssummen | `GET /api/log/self/stat` |
| Nutzung nach Stunde und Modell | `GET /api/data/self` |
| Aufladungen | `GET /api/user/topup/self` |
| Erstellen, Bearbeiten oder Löschen von API-Tokens | `POST`, `PUT` oder `DELETE /api/token/` |

Beträge werden zum Kurs 500000 Kontingent = 1 $ in USD umgerechnet. Die Preise entsprechen dem, was Ihr Konto tatsächlich bezahlt.

### API-Tokens erstellen und ändern

- Vor jedem Erstellen, Bearbeiten, Aktivieren, Deaktivieren oder Löschen sagt Ihnen der Agent, was er senden wird, und wartet auf Ihr OK.
- Wenn Sie nichts anderes verlangen, erhält ein neues Token wie in der Konsole unbegrenztes Kontingent und kein Ablaufdatum. Sie können ein Ausgabenlimit, ein Ablaufdatum oder eine Liste erlaubter Modelle anfordern.
- Nach dem Erstellen zeigt der Agent den vollständigen Schlüssel des Tokens einmal an. Kopieren Sie ihn in Ihre App oder Konfiguration.
- Das Löschen eines Tokens lässt sich nicht rückgängig machen, und Apps, die seinen Schlüssel verwenden, funktionieren sofort nicht mehr.

## Was der Skill nicht tut

- Abgesehen von API-Tokens ändert er nichts. Er leistet keine Zahlungen, löst keine Aufladecodes ein und bearbeitet Ihr Konto nicht. Dafür nutzen Sie die [Konsole](https://aiberm.com/console).
- Er setzt Ihr System-Zugriffstoken nicht zurück. Der Skill weist den Agenten an, diese Route nie aufzurufen.
- Er gibt die vollständigen Schlüssel Ihrer bestehenden API-Tokens nicht preis. Die Token-Liste enthält die vollständigen Schlüssel, der Agent zeigt sie aber maskiert an, etwa `sk-abcd****wxyz`. Einen vollständigen Schlüssel kopieren Sie unter [Token-Verwaltung](https://aiberm.com/console/token). Die einzige Ausnahme ist ein Token, das der Agent gerade für Sie erstellt hat.

<Callout client:load type="warning">
Diese Regeln sind Anweisungen an den Agenten, keine technische Sperre. Das Token erlaubt alles, was Ihre Anmeldung in der Konsole erlaubt. Verwenden Sie es nur mit Agenten und auf Rechnern, denen Sie vertrauen. Falls es in falsche Hände gerät, klicken Sie unter Persönliche Einstellungen auf **Neu generieren**.
</Callout>

## Fehlerbehebung

| Was Sie sehen | Was zu tun ist |
| --- | --- |
| Der Agent meldet, dass die Variablen fehlen | Setzen Sie beide, öffnen Sie ein neues Terminal und starten Sie eine neue Agent-Sitzung. |
| `未提供 New-Api-User` | `AIBERM_USER_ID` ist nicht gesetzt. |
| `New-Api-User 与登录用户不匹配` | `AIBERM_USER_ID` ist nicht die ID des Kontos, dem das Token gehört. Kopieren Sie die ID im selben Konto unter Persönliche Einstellungen. |
| `access token 无效` | Das Token ist falsch oder wurde neu generiert. Generieren Sie ein neues und aktualisieren Sie `AIBERM_ACCESS_TOKEN`. |
| Der Agent verwendet den Skill nicht | Prüfen Sie, ob die Datei unter `~/.claude/skills/aiberm/SKILL.md` oder `~/.agents/skills/aiberm/SKILL.md` liegt, und starten Sie dann eine neue Sitzung. Oder rufen Sie ihn direkt mit `/aiberm` (Claude Code, Grok Bot) oder `$aiberm` (Codex) auf. |
| `时间跨度不能超过 1 个月` | Die stündliche Nutzung umfasst pro Anfrage höchstens 30 Tage. Fragen Sie nach einem kürzeren Zeitraum. |

Den Quellcode des Skills und die vollständige Liste der Anfragen finden Sie im [aiberm-skill-Repository](https://github.com/aiberm/aiberm-skill). Fehler der Modell-API selbst sind unter [Fehlerbehandlung](/docs/de/error-handling/) beschrieben.
