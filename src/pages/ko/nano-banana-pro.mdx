# NanoBanana Pro

NanoBanana Pro는 Gemini의 이미지 생성 서비스입니다. 여러 종횡비(1:1, 16:9, 9:16 등)와 해상도(1K, 2K, 4K)를 지원합니다. 모든 해상도의 가격은 동일합니다. 4K는 생성 속도가 느려 권장하지 않습니다. [요금](/pricing?tab=gemini)을 참고하세요.

**엔드포인트**: `POST https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent`

**핵심 포인트**: 요청 본문 `contents`에 이미지 설명을 보내고, `generationConfig`에서 `responseModalities`, `imageConfig`(종횡비, 해상도)를 설정합니다. 생성된 이미지는 `candidates[0].content.parts`의 `inline_data`에 있습니다.

## 예제 코드

Python은 snake_case(예: `response_modalities`)를, REST/cURL은 camelCase(예: `responseModalities`)를 사용합니다. 의미는 같습니다.

### cURL 이미지 파라미터

아래는 cURL용 파라미터 이름(camelCase)입니다. Python에서는 snake_case를 사용하세요(예: `aspectRatio` → `aspect_ratio`).

**imageConfig** (`generationConfig.imageConfig` 또는 SDK `ImageConfig`):

- **aspectRatio** `string` — `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`
- **imageSize** `string` — `1K`, `2K`, `4K` (gemini-3-pro-image-preview만)

**기타 일반적인 generationConfig 필드:**

- **responseModalities** `string[]` — `["IMAGE"]` 또는 `["TEXT", "IMAGE"]`
- **temperature** `number` — 0–2, 높을수록 더 무작위
- **topP** `number` — 0–1, 다양성
- **maxOutputTokens** `number` — 예: 8192
- **systemInstruction** `object` — 예: `{"parts": [{"text": "..."}]}`
- **tools** `array` — 예: `[{"google_search": {}}]`

## Google Search 활성화

Gemini 스타일 API만 Google Search를 지원합니다. 구성에 `tools`를 전달하면 모델이 필요할 때 실시간 웹 정보를 사용합니다.

**기본적으로 권장하지 않습니다:** 지연 시간과 비용이 늘어나며, 이미지 전용 사용에는 필요하지 않습니다. 검색이 필요 없으면 끄세요.

**Python (SDK):**

```python
config = types.GenerateContentConfig(
    # ... other params like response_modalities, image_config
    tools=[{"google_search": {}}]
)
response = client.models.generate_content(model=model, contents=[prompt], config=config)
```

**cURL (REST):**

요청 본문 최상위에 `tools`를 추가합니다.

```bash
curl -X POST "https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "Your question"}]}],
    "generationConfig": { ... },
    "tools": [{"google_search": {}}]
  }'
```

## FAQ

- **응답에 이미지가 없음:** 모델이 `gemini-3-pro-image-preview`인지, 프롬프트가 명확한 이미지 설명인지 확인하세요.
- **디코드 오류:** `data:image/...;base64,` 뒤의 base64 문자열만 사용하고, 디코딩 전에 줄바꿈을 제거하세요.
