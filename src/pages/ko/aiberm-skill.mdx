# Aiberm Skill

[aiberm-skill](https://github.com/aiberm/aiberm-skill)은 코딩 에이전트에게 내 Aiberm 계정을 조회하는 방법을 알려 줍니다. 설치하고 나면 Claude Code, Codex 또는 다른 에이전트에게 "Aiberm 잔액이 얼마나 남았나요?"라고 물어볼 수 있습니다. 에이전트가 Aiberm API를 호출하고 알기 쉬운 말로 답합니다.

이 Skill은 잔액, 모델, 가격, API 토큰, 사용 로그, 충전 내역을 조회합니다. API 토큰을 생성, 수정, 활성화, 비활성화, 삭제할 수도 있으며, 변경할 때마다 먼저 확인을 받습니다.

<Callout client:load type="info">
Skill은 `SKILL.md` 파일이 들어 있는 폴더입니다. 질문이 Skill 설명과 맞으면 에이전트가 이 파일을 읽고 직접 `curl`을 실행합니다. 백그라운드에서 실행되는 것은 없으며, 빌드하거나 계속 실행해 둘 것도 없습니다.
</Callout>

## 사전 준비

- Aiberm 계정 ([여기에서 가입](https://aiberm.com/register))
- Skill을 지원하는 에이전트 (예: [Claude Code](/docs/ko/claude-code/), [Codex](/docs/ko/codex/))
- `curl`과 bash 호환 셸. macOS와 Linux에는 둘 다 기본으로 있습니다. Windows에서는 Claude Code가 Git Bash를 사용합니다.

## 1. 사용자 ID와 시스템 액세스 토큰 준비

Skill에는 두 값이 필요하며, 둘 다 [개인 설정](https://aiberm.com/console/personal)에서 확인할 수 있습니다.

| 값 | 위치 |
| --- | --- |
| 사용자 ID | 페이지 상단 헤더에 `ID: 123` 형식으로 표시됩니다 |
| 시스템 액세스 토큰 | **보안 설정** 탭 → **시스템 액세스 토큰** → **토큰 생성** |

Aiberm은 계정 요청마다 두 값을 모두 확인하며, ID는 토큰을 소유한 계정의 ID여야 합니다.

<Callout client:load type="warning">
시스템 액세스 토큰은 API 키(`sk-...`)가 **아닙니다**. 콘솔 로그인과 같은 역할을 하므로, 이 토큰을 가진 사람은 누구나 콘솔에서 내가 할 수 있는 일을 모두 할 수 있습니다. 다른 사람과 공유하지 마세요. **다시 생성**을 누르면 토큰이 교체되며, 이전 토큰을 쓰던 곳은 모두 작동하지 않습니다.
</Callout>

## 2. Skill 설치

**Claude Code** (2.1.275 이상): Claude Code 세션 안에서 다음을 실행하세요.

```text
/plugin install aiberm --marketplace aiberm/aiberm-skill
```

이전 버전에서는 먼저 `/plugin marketplace add aiberm/aiberm-skill`을 실행한 뒤 `/plugin install aiberm@aiberm`을 실행하세요. Claude Code가 요청하면 `/reload-plugins`를 실행하세요.

**Codex**: 터미널에서 다음 명령을 실행한 뒤 새 Codex 세션을 시작하세요.

```bash
codex plugin marketplace add aiberm/aiberm-skill
codex plugin add aiberm@aiberm
```

Codex 안에서 `/plugins`로 설치할 수도 있습니다.

**다른 에이전트**: [저장소](https://github.com/aiberm/aiberm-skill)를 클론하고, 그 안의 `skills/aiberm` 폴더를 에이전트가 Skill을 불러오는 폴더에 복사하세요.

## 3. 두 환경 변수 설정

에이전트는 환경 변수에서 값을 읽으므로, 에이전트를 시작하기 전에 설정하세요.

**macOS / Linux**: `~/.zshrc` 또는 `~/.bashrc`에 다음 줄을 추가한 뒤 새 터미널을 여세요.

```bash
export AIBERM_ACCESS_TOKEN="your-system-access-token"
export AIBERM_USER_ID="123"
```

**Windows (PowerShell)**: 아래 명령을 실행한 뒤 새 터미널을 여세요.

```powershell
setx AIBERM_ACCESS_TOKEN "your-system-access-token"
setx AIBERM_USER_ID "123"
```

<Callout client:load type="tip">
Claude Code에서만 사용한다면 두 변수를 `~/.claude/settings.json`의 `env` 블록에 넣어도 됩니다.
</Callout>

에이전트를 쓰기 전에 값이 맞는지 확인하려면 프로필을 요청해 보세요. `data.quota`를 500000으로 나눈 값이 USD 기준 남은 잔액입니다.

```bash
curl -sS "https://aiberm.com/api/user/self" \
  -H "Authorization: Bearer $AIBERM_ACCESS_TOKEN" \
  -H "New-Api-User: $AIBERM_USER_ID"
```

## 4. 에이전트에게 질문

새 에이전트 세션을 시작하고 평소 말투로 물어보세요.

- "Aiberm 잔액이 얼마나 남았나요?"
- "어제 Aiberm에서 쓴 금액을 모델별로 알려 주세요."
- "내 Aiberm API 토큰 목록과 토큰별 남은 할당량을 보여 주세요."
- "Aiberm에서 `claude-sonnet-5-5`는 100만 토큰당 얼마인가요?"
- "이번 주에 Aiberm에서 가장 많이 쓴 모델은 뭔가요?"
- "최근 Aiberm 충전 내역을 보여 주세요."
- "Aiberm에 `my-app`이라는 이름으로 한도 $5인 API 키를 만들어 주세요."
- "내 Aiberm 토큰 `old-test`를 비활성화해 주세요."

Claude Code에서는 `/aiberm:aiberm`으로 Skill을 직접 호출할 수도 있습니다.

| 물어보는 내용 | Skill이 읽는 API |
| --- | --- |
| 잔액과 총 사용 금액 | `GET /api/user/self` |
| 호출할 수 있는 모델 | `GET /api/user/models` |
| 모델 가격 | `GET /api/pricing` |
| API 토큰 | `GET /api/token/` |
| 사용 로그 | `GET /api/log/self` |
| 사용량 합계 | `GET /api/log/self/stat` |
| 시간별·모델별 사용량 | `GET /api/data/self` |
| 충전 내역 | `GET /api/user/topup/self` |
| API 토큰 생성, 수정, 삭제 | `POST`, `PUT` 또는 `DELETE /api/token/` |

금액은 할당량 500000 = $1 기준으로 USD로 환산됩니다. 가격은 내 계정이 실제로 지불하는 금액입니다.

### API 토큰 생성 및 변경

- 생성, 수정, 활성화, 비활성화, 삭제 전에는 매번 에이전트가 보낼 내용을 알려 주고 확인을 기다립니다.
- 따로 요청하지 않으면 새 토큰은 콘솔에서와 같이 할당량 무제한, 만료 없음으로 만들어집니다. 사용 한도, 만료일, 허용 모델 목록을 지정해 달라고 요청할 수 있습니다.
- 토큰을 만들면 에이전트가 전체 키를 한 번 보여 줍니다. 앱이나 구성 파일에 복사해 두세요.
- 토큰 삭제는 되돌릴 수 없으며, 해당 키를 쓰는 앱은 즉시 작동을 멈춥니다.

## Skill이 하지 않는 일

- API 토큰 외에는 아무것도 변경하지 않습니다. 결제, 충전 코드 사용, 계정 정보 수정은 하지 않습니다. 이런 작업은 [콘솔](https://aiberm.com/console)에서 하세요.
- 시스템 액세스 토큰을 재설정하지 않습니다. Skill은 에이전트에게 해당 엔드포인트를 절대 호출하지 말라고 지시합니다.
- 기존 API 토큰의 전체 키를 보여 주지 않습니다. 토큰 목록에는 전체 키가 들어 있지만, 에이전트는 `sk-abcd****wxyz`처럼 가려서 표시합니다. 전체 키는 [토큰 관리](https://aiberm.com/console/token)에서 복사하세요. 단, 에이전트가 방금 만들어 준 토큰은 예외입니다.

<Callout client:load type="warning">
이 규칙은 에이전트에게 주는 지시일 뿐, 기술적인 잠금 장치가 아닙니다. 이 토큰으로는 콘솔 로그인으로 할 수 있는 모든 작업이 가능합니다. 신뢰할 수 있는 에이전트와 컴퓨터에서만 사용하세요. 토큰이 유출되었다면 개인 설정에서 **다시 생성**을 누르세요.
</Callout>

## 문제 해결

| 증상 | 조치 |
| --- | --- |
| 에이전트가 변수가 없다고 함 | 두 변수를 모두 설정하고 새 터미널을 연 뒤 새 에이전트 세션을 시작하세요. |
| `未提供 New-Api-User` | `AIBERM_USER_ID`가 설정되지 않았습니다. |
| `New-Api-User 与登录用户不匹配` | `AIBERM_USER_ID`가 토큰을 소유한 계정의 ID가 아닙니다. 같은 계정의 개인 설정에서 ID를 복사하세요. |
| `access token 无效` | 토큰이 잘못되었거나 다시 생성되었습니다. 새 토큰을 생성하고 `AIBERM_ACCESS_TOKEN`을 업데이트하세요. |
| 에이전트가 Skill을 사용하지 않음 | 새 세션을 시작하세요. Claude Code에서는 `/plugin`에 `aiberm`이 활성화되어 있는지 확인하거나 `/aiberm:aiberm`을 입력하세요. Codex에서는 `codex plugin list`에 `aiberm@aiberm`이 설치됨으로 표시되는지 확인하세요. |
| `时间跨度不能超过 1 个月` | 시간별 사용량은 요청당 최대 30일까지 조회할 수 있습니다. 더 짧은 기간으로 요청하세요. |

Skill 소스와 전체 요청 목록은 [aiberm-skill 저장소](https://github.com/aiberm/aiberm-skill)에 있습니다. 모델 API 자체의 오류는 [오류 처리](/docs/ko/error-handling/)를 참고하세요.
