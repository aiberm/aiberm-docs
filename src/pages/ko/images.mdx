# 이미지

aiberm는 현재 다음 이미지 기능을 지원합니다. 각 페이지에서 사용법과 연동 세부 정보를 확인하세요.

## 이미지 생성

**[GPT Image 2](/docs/ko/gpt-image-2/)** — OpenAI 호환 이미지 엔드포인트로 이미지를 생성하고 편집합니다.

**[NanoBanana Pro](/docs/ko/nano-banana-pro/)** — 텍스트 설명으로 이미지를 생성합니다.

## 이미지 편집

**[GPT Image 2](/docs/ko/gpt-image-2/)** — 참조 이미지, 마스크, 스트리밍 부분 이미지를 사용합니다.

**[NanoBananaPro Edit](/docs/ko/nano-banana-pro-edit/)** — 기존 이미지를 편집하고 수정합니다.
