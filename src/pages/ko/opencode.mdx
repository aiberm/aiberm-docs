# OpenCode CLI 설정

OpenCode CLI를 Aiberm API와 함께 사용하도록 구성하는 방법을 안내합니다. 이 가이드는 Windows, macOS, Linux의 설치와 설정을 다룹니다.

## OpenCode란 무엇인가요?

OpenCode는 개발자를 위한 강력한 AI 지원을 제공하는 Go 기반 오픈소스 명령줄 프로그래밍 도구(CLI)입니다. 직관적인 터미널 사용자 인터페이스(TUI)를 제공하며 OpenAI, Anthropic, Gemini 등 여러 LLM 공급자를 지원합니다.

OpenCode를 **Aiberm API**와 연동하면 하나의 키와 하나의 base URL로 Aiberm에서 제공하는 모든 모델(Claude, GPT, Gemini 등)에 통합 인터페이스로 접근할 수 있습니다.

## 사전 준비

시작하기 전에 다음이 준비되어 있는지 확인하세요.

- Aiberm 계정 ([여기에서 가입](https://aiberm.com/register))
- Aiberm API 키 ([키 발급하기](https://aiberm.com/console/token))
- 컴퓨터에서 터미널/명령 프롬프트 사용 가능

### 터미널 에뮬레이터

OpenCode는 최신 터미널 에뮬레이터가 필요합니다. 권장 옵션은 다음과 같습니다.

- **WezTerm** (크로스 플랫폼)
- **Alacritty** (크로스 플랫폼)
- **Ghostty** (Linux 및 macOS)
- **Kitty** (Linux 및 macOS)

Windows 사용자는 PowerShell 또는 Windows Terminal을 사용할 수도 있습니다. macOS 사용자는 내장 Terminal.app 또는 iTerm2를 사용할 수 있습니다. Linux 사용자는 내장 터미널이나 GNOME Terminal, Konsole 등을 사용할 수 있습니다.

## 설치

아래 운영체제별 설치 안내를 선택하세요.

### macOS & Linux

가장 쉬운 방법은 설치 스크립트를 사용하는 것입니다.

```bash
curl -fsSL https://opencode.ai/install | bash
```

또는 Homebrew 사용:

```bash
brew install anomalyco/tap/opencode
```

**설치 확인:**
```bash
opencode --version
```

### Windows

Windows 사용자는 먼저 [Node.js](https://nodejs.org/en/download)를 설치한 뒤 NPM으로 설치하세요.

```bash
npm i -g opencode-ai@latest
```

또는 Chocolatey 사용:

```bash
choco install opencode
```

또는 Scoop 사용:

```bash
scoop bucket add extras
scoop install extras/opencode
```

**설치 확인:**
```bash
opencode --version
```

그래픽 인터페이스를 선호한다면 OpenCode 데스크톱 앱도 있습니다. [OpenCode Download Page](https://opencode.ai/download)에서 받을 수 있습니다.

## 구성

### 1단계: 공급자 초기화

설치 후 OpenCode를 실행하기 전에 터미널에서 다음 명령을 실행하세요.

```bash
opencode auth login
```

1. 공급자 목록에서 **other**를 선택합니다 (맨 아래에 있으며 검색할 수 있습니다)
2. **Provider ID**를 입력합니다: `aiberm`을 입력하세요
3. **API Key token**을 입력합니다: 아무 값이나 입력해도 됩니다(예: `admin`). 실제 키는 구성 파일에서 참조합니다

이 단계는 OpenCode의 로컬 자격 증명 관리자에 사용자 지정 공급자를 등록합니다.

### 2단계: 구성 파일 편집

OpenCode 구성 디렉터리를 엽니다.

**Windows:**

`Win + R`을 누르고 다음을 붙여넣은 뒤 Enter를 누릅니다.

```
%userprofile%\.config\opencode
```

**macOS / Linux:**

터미널에서 다음을 실행합니다.

```bash
cd ~/.config/opencode
```

또는 Finder/파일 관리자에서 `~/.config/opencode/`로 이동합니다.

이 디렉터리에서 `opencode.json`을 만들거나 편집합니다. 아래는 Claude 모델이 포함된 구성 예시입니다.

```json
{
    "$schema": "https://opencode.ai/config.json",
    "provider": {
        "aiberm": {
            "npm": "@ai-sdk/anthropic",
            "name": "Aiberm",
            "options": {
                "baseURL": "https://aiberm.com/v1",
                "apiKey": "sk-your-aiberm-api-key"
            },
            "models": {
                "claude-opus-4-5-20251101": {
                    "name": "Claude-4.5-Opus"
                },
                "claude-sonnet-4-5-20250929": {
                    "name": "Claude-4.5-Sonnet"
                },
                "claude-haiku-4-5-20251001": {
                    "name": "Claude-4.5-Haiku"
                }
            }
        }
    }
}
```

Aiberm에서 제공하는 다른 모델도 추가할 수 있습니다. 예를 들어 OpenAI GPT 모델을 추가하려면 다음과 같이 합니다.

```json
{
    "$schema": "https://opencode.ai/config.json",
    "provider": {
        "aiberm": {
            "npm": "@ai-sdk/openai",
            "name": "Aiberm",
            "options": {
                "baseURL": "https://aiberm.com/v1",
                "apiKey": "sk-your-aiberm-api-key"
            },
            "models": {
                "openai/gpt-4.1": {
                    "name": "GPT-4.1"
                },
                "openai/gpt-4.1-mini": {
                    "name": "GPT-4.1 Mini"
                },
                "openai/gpt-4.1-nano": {
                    "name": "GPT-4.1 Nano"
                },
                "openai/gpt-4o": {
                    "name": "GPT-4o"
                },
                "openai/gpt-4o-mini": {
                    "name": "GPT-4o Mini"
                }
            }
        }
    }
}
```

Aiberm에서 사용 가능한 모든 모델은 [모델 목록](/docs/ko/models) 페이지 또는 [Aiberm Pricing](https://aiberm.com/pricing)을 확인하세요.

**중요:**

- `"sk-your-aiberm-api-key"`를 [Aiberm Console](https://aiberm.com/console/token)의 실제 API Key로 바꾸세요
- JSON 형식은 기호에 민감합니다

## 구성 확인

구성 파일을 저장한 뒤 터미널을 다시 시작하고 작업 디렉터리로 이동합니다.

```bash
cd your-working-directory
```

OpenCode를 실행합니다.

```bash
opencode
```

채팅 인터페이스에서 다음 명령을 입력합니다.

```
/models
```

모델 목록에 Aiberm과 해당 모델이 보여야 합니다. 하나를 선택하면 바로 사용할 수 있습니다.

## 모델 전환

OpenCode 인터페이스에서 `/models` 명령을 입력한 뒤 목록에서 원하는 모델을 선택하세요.

**Aiberm을 통해 사용할 수 있는 모델 예시:**

- **anthropic/claude-sonnet-4-5-20250514**: Anthropic의 Claude 4.5 Sonnet
- **anthropic/claude-opus-4-20250514**: Anthropic의 Claude 4 Opus
- **openai/gpt-4.1**: OpenAI의 GPT-4.1
- **openai/gpt-4o-mini**: OpenAI의 GPT-4o Mini
- **google/gemini-3-pro**: Google의 Gemini 3 Pro
- 그리고 더 많은 모델...

사용 가능한 모델의 전체 목록은 [Aiberm Pricing](https://aiberm.com/pricing)을 참고하세요.

## 문제 해결

### 구성 변경이 적용되지 않음

- OpenCode를 다시 시작하세요
- `opencode.json` 문법을 확인하세요 (JSON 형식)
- 구성 파일 경로가 올바른지 확인하세요

### 401/403 오류

- **401 오류**: API Key가 설정되지 않았거나 유효하지 않음
- **403 오류**: 권한이 부족하거나 키가 만료됨
- 구성 파일의 `apiKey`를 확인하세요
- [Aiberm Console](https://aiberm.com/console/token)에서 API 키를 확인하세요

### OpenCode를 찾을 수 없음

**macOS/Linux:**
```bash
# Check if OpenCode is in your PATH
which opencode

# If not found, try reinstalling:
curl -fsSL https://opencode.ai/install | bash
```

**Windows:**
- Node.js가 올바르게 설치되어 있는지 확인하세요
- npm으로 다시 설치해 보세요: `npm i -g opencode-ai@latest`

### 구성 파일 위치

`opencode.json` 구성 파일은 다음 위치에 두어야 합니다.

- **Windows**: `C:\Users\{username}\.config\opencode\opencode.json`
- **macOS / Linux**: `~/.config/opencode/opencode.json`

## 참고 사항

- OpenCode는 전용 프로젝트 폴더에서 실행하세요. 시스템 폴더나 자격 증명이 있는 디렉터리 같은 민감한 디렉터리에서는 실행하지 마세요. OpenCode는 현재 작업 디렉터리부터 동작합니다.
- OpenCode는 JSON 형식의 구성 파일을 사용합니다. 구성 파일 문법이 올바른지 확인하세요. 온라인 JSON 검사기로 형식을 확인할 수 있습니다.
- OpenCode는 사용자가 명시적으로 허용할 때만 파일 내용을 읽습니다. 전용 프로젝트 폴더에서 사용하는 것이 좋습니다.
- 중국어 입력과 출력을 완전히 지원합니다.
