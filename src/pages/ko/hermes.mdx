# Hermes Agent 설정

이 가이드는 [Hermes Agent](https://hermes-agent.nousresearch.com/)가 Aiberm를 모델 공급자로 사용하도록 구성하는 방법을 설명합니다. Hermes Agent는 Nous Research가 개발한 오픈소스 AI 에이전트로, 터미널에서 실행되며 Telegram, Discord, Slack, WhatsApp, Signal을 포함한 메시징 플랫폼과 연동됩니다.

Aiberm는 OpenAI 호환 `/v1` API를 제공하므로, 플러그인을 설치하거나 소스 코드를 수정하지 않고도 Hermes Agent에 사용자 지정 공급자로 등록할 수 있습니다. 구성이 끝나면 하나의 API 키로 Aiberm에서 제공하는 모든 모델(Claude, GPT, Gemini, DeepSeek, Kimi, MiniMax, GLM, Grok 포함)에 접근할 수 있습니다.

## 사전 준비

- Aiberm 계정 ([가입하기](https://aiberm.com/register))
- Aiberm API 키 ([키 발급하기](https://aiberm.com/console/token))
- Hermes Agent 설치 — [공식 설치 가이드](https://hermes-agent.nousresearch.com/docs/getting-started/)를 참고하세요

빠른 설치 (Linux / macOS / WSL2):

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

## Aiberm를 공급자로 구성하기

Hermes Agent는 구성을 `~/.hermes/config.yaml`에 저장합니다. 파일을 열고 `providers:` 섹션 아래에 `aiberm` 항목을 추가하세요.

> **Vim 같은 명령줄 에디터가 익숙하지 않다면**, 운영체제의 기본 에디터로 구성 파일을 열 수 있습니다.
>
> - **macOS**: **Finder**를 열고 `Shift + Command + G`를 누른 뒤 대화 상자에 `~/.hermes`를 입력하고 Return을 누릅니다. `config.yaml` 파일을 찾아 마우스 오른쪽 버튼으로 클릭한 뒤 **다음으로 열기 → TextEdit**를 선택합니다.
> - **Windows**: **파일 탐색기**를 열고 주소 표시줄에 `%USERPROFILE%\.hermes`를 입력한 뒤 Enter를 누릅니다. `config.yaml`을 마우스 오른쪽 버튼으로 클릭하고 **연결 프로그램 → 메모장**을 선택합니다.
>
> 편집이 끝나면 **파일을 저장한 뒤** (macOS는 `Command + S`, Windows는 `Ctrl + S`) 아래에 설명된 재시작 단계로 진행하세요.

### 필드 참조

| 필드 | 필수 | 설명 |
|-------|----------|-------------|
| `base_url` | 예 | Aiberm의 OpenAI 호환 엔드포인트입니다. `https://aiberm.com/v1`로 설정하세요. |
| `api_key` | 예 | Aiberm API 키입니다. [콘솔](https://aiberm.com/console/token)에서 확인할 수 있습니다. |
| `type` | 예 | 프로토콜 유형입니다. `openai`로 설정하세요. Aiberm는 OpenAI Chat Completions 사양을 따릅니다. |
| `default_model` | 예 | 모델을 명시하지 않았을 때 사용하는 모델입니다. |
| `models` | 권장 | `/model` 선택기에 표시되는 모델 목록입니다. Hermes는 이 목록에 있는 항목(및 `default_model`)만 보여 줍니다. 생략하면 선택기에 버튼이 하나만 표시됩니다. |

최상위 `model:` 섹션은 활성 공급자와 기본 모델을 지정합니다. 이전에 다른 공급자를 사용 중이라면 `provider:`를 `aiberm`로 설정하고 `default:`를 `models:` 블록에 있는 모델로 설정하세요.

## 사용법

구성을 업데이트한 뒤 Hermes를 다시 시작하세요(CLI: 종료 후 `hermes`를 다시 실행, 게이트웨이: `hermes gateway restart`).

**터미널에서 (CLI):**

```
/model
```

Hermes가 대화형 모델 선택기를 엽니다. **Aiberm**를 선택한 뒤 원하는 모델을 고르세요. 직접 전환할 수도 있습니다.

```
/model claude-opus-4-7
/model gpt-5.4 --global
```

`--global`을 추가하면 변경이 `config.yaml`에 저장됩니다. 생략하면 현재 세션에만 적용됩니다.

**Telegram, Discord, Slack 또는 WhatsApp에서:**

봇에 `/model`을 보내세요. 자격 증명이 구성된 모든 공급자를 나열하는 인라인 키보드가 반환됩니다. **Aiberm**를 선택하면 페이지가 나뉜 모델 목록(페이지당 8개, Prev / Next 탐색)이 표시되고, 모델을 탭하면 전환됩니다.

## 전체 모델 카탈로그 보기

위의 `models:` 목록은 선별된 하위 집합입니다. Aiberm가 현재 제공하는 모든 모델을 보려면 API를 직접 조회하세요.

```bash
curl -H "Authorization: Bearer sk-your-aiberm-api-key" \
     https://aiberm.com/v1/models | jq -r '.data[].id'
```

사용하고 싶은 모델 ID를 `models:` 블록에 추가한 뒤 Hermes를 다시 시작하세요. 그러면 `/model` 선택기에 나타납니다.

## 환경 변수 사용하기 (선택 사항)

API 키를 `config.yaml`에 저장하고 싶지 않다면 환경 변수에서 읽을 수 있습니다. 다음을 설정하세요.

```bash
export AIBERM_API_KEY=sk-your-aiberm-api-key
```

그런 다음 `config.yaml`에서 `key_env`로 참조합니다.

```yaml
providers:
  aiberm:
    base_url: https://aiberm.com/v1
    key_env: AIBERM_API_KEY
    type: openai
    default_model: claude-sonnet-4-6
```

## 문제 해결

### `/model`에 Aiberm 버튼이 하나만 표시됨

`providers.aiberm` 블록에 `models:` 목록이 없습니다. Hermes 선택기는 모델이 8개를 넘을 때만 페이지를 나눕니다. 위에 나온 선별 목록을 추가한 뒤 Hermes를 다시 시작하세요.

### 401 Unauthorized

- [Aiberm 콘솔](https://aiberm.com/console/token)에서 API 키를 확인하세요.
- 키가 구성 최상위가 아니라 `providers.aiberm.api_key` 아래에 있는지 확인하세요.

### 모델을 찾을 수 없음

Aiberm 모델 카탈로그는 시간이 지나며 바뀝니다. 목록에 있던 모델이 이름이 바뀌거나 더 이상 제공되지 않을 수 있습니다. `/v1/models`를 다시 조회한 뒤(위 참고) `models:` 목록을 업데이트하세요.

### 구성이 로드되었는지 확인하는 방법

```bash
hermes doctor
```

이 명령은 현재 활성 공급자와 모델을 포함한 진단 보고서를 출력합니다.
