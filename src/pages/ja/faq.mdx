# よくある質問

## Aiberm の 2 種類の Claude モデルセットの違いは何ですか？

Aiberm は用途に応じて 2 種類の Claude モデルセットを提供しています。

- **`claude-` プレフィックスのモデル**: 81% オフの割引価格で利用でき、コーディング用途に最適です。Claude Code はデフォルトで `claude-` プレフィックスのモデルをサポートします。
- **`anthropic/` プレフィックスのモデル**: AWS 経由でルーティングされ、公式価格から約 28% オフです。

## Aiberm のモデルはキャッシュに対応していますか？

はい。すべての Aiberm Claude モデルはプロンプトキャッシュに対応しています。キャッシュは高いヒット率になるよう最適化されています。キャッシュがヒットした場合、価格に 0.1 が乗算されます。他のモデルもキャッシュに対応しています。

## 請求書はどうやって入手できますか？

- **セルフサービス請求書**: [https://meiguo.app/invoice](https://meiguo.app/invoice)
- **法人銀行振込**の請求書にも対応しています。グループ管理者 @Folyd までご連絡ください。
- **非法人の振込**で中国の発票（Fapiao）が必要な場合、最低金額は $500 です。$500 未満の場合は追加で 8% の税金サーチャージがかかります。
