# NanoBanana Pro

NanoBanana Pro は Gemini の画像生成サービスです。複数のアスペクト比（1:1、16:9、9:16 など）と解像度（1K、2K、4K）に対応しています。すべての解像度で価格は同じです。4K は生成が遅く、推奨しません。詳しくは [料金](/pricing?tab=gemini) を参照してください。

**エンドポイント**: `POST https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent`

**ポイント**: リクエストボディの `contents` に画像の説明を送り、`generationConfig` で `responseModalities` と `imageConfig`（アスペクト比、解像度）を設定します。生成された画像は `candidates[0].content.parts` の `inline_data` に含まれます。

## コード例

Python は snake_case（例: `response_modalities`）、REST/cURL は camelCase（例: `responseModalities`）を使います。意味は同じです。

### cURL の画像パラメータ

以下は cURL 向けのパラメータ名（camelCase）です。Python では snake_case を使います（例: `aspectRatio` → `aspect_ratio`）。

**imageConfig**（`generationConfig.imageConfig` または SDK の `ImageConfig`）:

- **aspectRatio** `string` — `1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`、`21:9`
- **imageSize** `string` — `1K`、`2K`、`4K`（gemini-3-pro-image-preview のみ）

**その他のよく使う generationConfig フィールド:**

- **responseModalities** `string[]` — `["IMAGE"]` または `["TEXT", "IMAGE"]`
- **temperature** `number` — 0〜2。高いほどランダムになります
- **topP** `number` — 0〜1。多様性を制御します
- **maxOutputTokens** `number` — 例: 8192
- **systemInstruction** `object` — 例: `{"parts": [{"text": "..."}]}`
- **tools** `array` — 例: `[{"google_search": {}}]`

## Google Search を有効にする

Google Search に対応しているのは Gemini スタイルの API のみです。設定に `tools` を渡すと、モデルは必要に応じてリアルタイムのウェブ情報を使います。

**デフォルトでは非推奨です:** レイテンシとコストが増えます。画像のみの用途では不要です。検索が不要ならオフにしてください。

**Python（SDK）:**

```python
config = types.GenerateContentConfig(
    # ... other params like response_modalities, image_config
    tools=[{"google_search": {}}]
)
response = client.models.generate_content(model=model, contents=[prompt], config=config)
```

**cURL（REST）:**

リクエストボディのトップレベルに `tools` を追加します。

```bash
curl -X POST "https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "Your question"}]}],
    "generationConfig": { ... },
    "tools": [{"google_search": {}}]
  }'
```

## FAQ

- **レスポンスに画像がない:** モデルが `gemini-3-pro-image-preview` であること、プロンプトが明確な画像説明であることを確認してください。
- **デコードエラー:** `data:image/...;base64,` のあとの base64 文字列だけを使い、デコード前に改行を取り除いてください。
