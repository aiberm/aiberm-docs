# モデル一覧

現在のユーザーが利用できるすべての AI モデルの一覧を取得します。モデル ID、名前、プロバイダ、詳細情報が含まれます。

<Callout client:load type="info" title="モデル一覧とトークングループについて">
一覧に返されるモデルは、API KEY が属するトークングループによって決まります。トークングループは、コンソール → API Tokens でトークンを作成または編集するときに選択できます。
</Callout>

## エンドポイント

`GET https://aiberm.com/v1/models`

## レスポンスフィールド

**トップレベルフィールド:**
- `success` - 真偽値。リクエストが成功したかどうかを示します
- `data` - モデルオブジェクトの配列（成功時のみ返されます）
- `message` - エラーメッセージ（失敗時のみ返されます）

**モデルオブジェクトのフィールド:**
- `id` - モデルの一意な識別子
- `object` - オブジェクトタイプ。固定で "model"
- `created` - モデル作成時のタイムスタンプ
- `owned_by` - モデルプロバイダ（例: openai、anthropic）
- `supported_endpoint_types` - 対応する API エンドポイントタイプの配列

## 対応エンドポイントタイプ

- `chat` - Chat Completion
- `completion` - Text Completion
- `embedding` - Text Embedding
- `image` - Image Generation
- `audio` - Audio Processing
- `rerank` - Rerank

## 重要な注意点

<Callout client:load type="info" title="認証が必要です">
有効な API トークンを指定する必要があります。トークンによって、ユーザーがアクセスできるモデルが決まります。
</Callout>

<Callout client:load type="info" title="権限管理">
返されるモデル一覧は、ユーザーグループとトークングループに基づいてフィルタされ、ユーザーがアクセス権限を持つモデルだけが表示されます。
</Callout>

## よくあるエラー

- `401 Unauthorized` - API トークンが無効、または期限切れです
- `403 Forbidden` - ユーザーにアクセス権限がありません
- `500 Internal Server Error` - 内部サーバーエラーです
