# 認証

すべての API リクエストには認証が必要です。Bearer Token 認証を使用して、API 呼び出しの安全性と信頼性を確保します。

## API キーの取得

コンソール → API Tokens で API キーを作成・管理してください。

<Callout client:load type="info" title="作成手順">
1. Aiberm アカウントにログインします
2. コンソールページへ移動します
3. 左メニューの「API Tokens」をクリックします
4. 「New Token」ボタンをクリックします
5. トークン名と権限を設定します
6. 生成された API キーをコピーします
</Callout>

## セキュリティに関する注意

- API キーは安全に保管し、クライアントサイドのコードに埋め込まないでください
- アカウントのセキュリティ向上のため、API キーは定期的にローテーションしてください
- API キーが漏洩した場合は、直ちにコンソールで削除し、新しいキーを再発行してください
- API キーはハードコードせず、環境変数で管理してください

## よくあるエラー

<Callout client:load type="error" title="401 Unauthorized">
無効または期限切れの API キーです

**対処法:** API キーが正しいか確認するか、新しい API キーを再発行してください
</Callout>

<Callout client:load type="error" title="403 Forbidden">
権限不足、またはアカウントが制限されています

**対処法:** アカウントの状態を確認し、管理者に適切な権限を依頼してください
</Callout>
