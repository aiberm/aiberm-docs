# Codex CLI のセットアップ

Codex CLI を Aiberm の API で使うための設定方法を説明します。このガイドでは Windows、macOS、Linux 向けのインストールと設定を扱います。

## Codex CLI とは

Codex CLI は、コード関連のターミナル作業向けに設計された OpenAI のコマンドラインインターフェースです。一般的なチャットツールと比べて、より明確で実行しやすいコード変更を重視した、エンジニアリング向けの出力が特徴です。Aiberm を使うように設定すると、コスト効率の良いエンドポイントから複数の AI モデルにアクセスできます。

## 前提条件

開始する前に、次を用意してください。

- Aiberm アカウント（[こちらから登録](https://aiberm.com/register)）
- Aiberm API キー（[キーを取得](https://aiberm.com/console/token)）
- Node.js v20 以上と npm

## インストール

npm で Codex CLI をグローバルインストールします。

```bash
npm install -g @openai/codex
```

**インストールの確認:**
```bash
codex --version
```

バージョン番号が表示されるはずです。

## 設定

Codex CLI は設定に `config.toml` を使います。設定ディレクトリの場所は OS によって異なります。

- **Windows**: `%userprofile%\.codex`
- **macOS/Linux**: `~/.codex`

### 方法 1: 手動設定

設定ディレクトリに移動し、`config.toml` を作成または編集します。

**macOS/Linux:**
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```

**Windows:**
```powershell
mkdir $env:USERPROFILE\.codex -Force
notepad $env:USERPROFILE\.codex\config.toml
```

次の設定を追加します。

```toml
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.com/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
```

**重要:** `sk-your-aiberm-api-key` を Aiberm で発行した実際の API キーに置き換えてください。キーは `config.toml` に平文で保存されます。このファイルを Git にコミットしたり、他の人と共有したりしないでください。

### 方法 2: ワンコマンドでの設定

**macOS/Linux:**
```bash
mkdir -p ~/.codex && cat > ~/.codex/config.toml << 'EOF'
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.com/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
EOF
```

**Windows PowerShell:**
```powershell
$configPath = "$env:USERPROFILE\.codex"
New-Item -ItemType Directory -Force -Path $configPath | Out-Null
@"
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.com/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
"@ | Out-File -FilePath "$configPath\config.toml" -Encoding utf8
```

**重要:** 設定内の `sk-your-aiberm-api-key` を、Aiberm で発行した実際の API キーに置き換えてください。キーは `config.toml` に平文で保存されます。このファイルを Git にコミットしたり、他の人と共有したりしないでください。

## 設定の確認

**Node.js のインストール確認:**
```bash
node -v
npm -v
```

**Codex CLI のインストール確認:**
```bash
codex --version
```

**API 接続のテスト:**
```bash
codex "Hi"
```

正しく設定されていれば、Codex CLI は Aiberm の API を使って応答します。

## トラブルシューティング

### 401 Unauthorized エラー

- API キーが正しいか確認します: [コンソール → API Keys](https://aiberm.com/console/token)
- `experimental_bearer_token` が実際の Aiberm API キーになっており、プレースホルダーがそのまま保存されていないことを確認します

### 403 Forbidden エラー

- API キーの有効性を確認します
- [https://aiberm.com/console](https://aiberm.com/console) でアカウント残高を確認します
- API キーがリクエストしたモデルにアクセスできることを確認します

### ネットワークエラー

- インターネット接続を確認します
- ブラウザで https://aiberm.com にアクセスできるか確認します
- ファイアウォールが送信 HTTPS 接続を許可していることを確認します
- `config.toml` の `base_url` が正しいことを確認します: `https://aiberm.com/v1`

### 設定が反映されない

- `config.toml` を編集したあとにターミナルを再起動します
- TOML の書式を確認します（余分な空白や引用符の誤りがないこと）
- お使いの OS に対して設定ファイルの場所が正しいことを確認します
- ファイル名が `config.toml` であることを確認します（`config.toml.txt` ではないこと）

### Codex コマンドが見つからない

**macOS/Linux:**
```bash
# Check if npm global bin is in PATH
npm config get prefix

# If needed, add to PATH in ~/.zshrc or ~/.bashrc:
export PATH="$(npm config get prefix)/bin:$PATH"
```

**Windows:**
- npm のグローバルパスがシステムの PATH に含まれていることを確認します
- npm インストール後はターミナルを再起動します
