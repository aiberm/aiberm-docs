# Aiberm Skill

[aiberm-skill](https://github.com/aiberm/aiberm-skill) は、コーディングエージェントがご自身の Aiberm アカウントを読み取れるようにする Skill です。インストールすれば、Claude Code、Codex などのエージェントに「Aiberm の残高はあといくら？」と聞けます。エージェントが Aiberm API を呼び出し、わかりやすい言葉で答えます。

この Skill は、残高、モデル、料金、API トークン、使用ログ、チャージ履歴を読み取ります。API トークンの作成、編集、有効化、無効化、削除もでき、変更のたびに事前にあなたの確認を求めます。

<Callout client:load type="info">
Skill とは、`SKILL.md` ファイルを含むフォルダのことです。質問が Skill の説明に合うと、エージェントがこのファイルを読み、自分で `curl` を実行します。バックグラウンドで動くものはなく、ビルドや常駐が必要なものもありません。
</Callout>

## 前提条件

- Aiberm アカウント（[登録](https://aiberm.com/register)）
- Skill に対応したエージェント（[Claude Code](/docs/ja/claude-code/) や [Codex](/docs/ja/codex/) など）
- `curl` と bash 互換のシェル。macOS と Linux には最初から入っています。Windows では、Claude Code は Git Bash を使います。

## 1. ユーザー ID とシステムアクセストークンを取得する

Skill には 2 つの値が必要です。どちらも [アカウント設定](https://aiberm.com/console/personal) で確認できます。

| 値 | 確認場所 |
| --- | --- |
| ユーザー ID | ページ上部のヘッダーに `ID: 123` の形で表示されます |
| システムアクセストークン | **セキュリティ設定** タブ → **システムアクセストークン** → **トークン生成** |

Aiberm はアカウントへのリクエストのたびに両方を確認します。また、ID はトークンを所有するアカウントのものでなければなりません。

<Callout client:load type="warning">
システムアクセストークンは API キー（`sk-...`）では**ありません**。コンソールへのログインと同じように働き、これを持っている人は、あなたがコンソールでできることを何でもできます。他人に知られないようにしてください。**再生成** を押すとトークンが置き換わり、古いトークンを使っているものはすべて動かなくなります。
</Callout>

## 2. Skill をインストールする

**Claude Code**（2.1.275 以降）: Claude Code のセッション内で次を実行します。

```text
/plugin install aiberm --marketplace aiberm/aiberm-skill
```

それより古いバージョンでは、先に `/plugin marketplace add aiberm/aiberm-skill` を実行してから、`/plugin install aiberm@aiberm` を実行します。Claude Code に求められた場合は、`/reload-plugins` を実行してください。

**Codex**: ターミナルで次のコマンドを実行し、新しい Codex セッションを開始します。

```bash
codex plugin marketplace add aiberm/aiberm-skill
codex plugin add aiberm@aiberm
```

Codex 内の `/plugins` からインストールすることもできます。

**その他のエージェント**: [リポジトリ](https://github.com/aiberm/aiberm-skill) をクローンし、その中の `skills/aiberm` フォルダを、エージェントが Skill を読み込むフォルダにコピーします。

## 3. 2 つの環境変数を設定する

エージェントは自身の環境変数から値を読み取ります。そのため、エージェントを起動する前に設定しておいてください。

**macOS / Linux**: `~/.zshrc` または `~/.bashrc` に次の行を追加し、新しいターミナルを開きます。

```bash
export AIBERM_ACCESS_TOKEN="your-system-access-token"
export AIBERM_USER_ID="123"
```

**Windows（PowerShell）**: 次のコマンドを実行し、新しいターミナルを開きます。

```powershell
setx AIBERM_ACCESS_TOKEN "your-system-access-token"
setx AIBERM_USER_ID "123"
```

<Callout client:load type="tip">
Claude Code だけで使う場合は、代わりに `~/.claude/settings.json` の `env` ブロックに両方の変数を書くこともできます。
</Callout>

エージェントを使う前に値を確認するには、プロフィールをリクエストします。`data.quota` を 500000 で割った値が、USD 建ての残高です。

```bash
curl -sS "https://aiberm.com/api/user/self" \
  -H "Authorization: Bearer $AIBERM_ACCESS_TOKEN" \
  -H "New-Api-User: $AIBERM_USER_ID"
```

## 4. エージェントに聞く

新しいエージェントセッションを開始し、普段の言葉で質問します。

- 「Aiberm の残高、あといくら残ってる？」
- 「昨日 Aiberm でいくら使った？モデル別に教えて。」
- 「Aiberm の API トークンを一覧にして、それぞれの残りクォータも出して。」
- 「`claude-sonnet-5-5` って、Aiberm だと 100 万トークンあたりいくら？」
- 「今週 Aiberm で一番使ったモデルはどれ？」
- 「最近の Aiberm のチャージ履歴を見せて。」
- 「Aiberm で `my-app` って名前の API キーを、上限 $5 で作って。」
- 「Aiberm のトークン `old-test` を無効にして。」

Claude Code では、`/aiberm:aiberm` で Skill を直接呼び出すこともできます。

| 質問の内容 | Skill が読み取る API |
| --- | --- |
| 残高と累計利用額 | `GET /api/user/self` |
| 呼び出せるモデル | `GET /api/user/models` |
| モデルの料金 | `GET /api/pricing` |
| API トークン | `GET /api/token/` |
| 使用ログ | `GET /api/log/self` |
| 使用量の合計 | `GET /api/log/self/stat` |
| 時間別・モデル別の使用量 | `GET /api/data/self` |
| チャージ履歴 | `GET /api/user/topup/self` |
| API トークンの作成・編集・削除 | `POST`、`PUT`、または `DELETE /api/token/` |

金額は 500000 クォータ = $1 で USD に換算されます。料金は、ご自身のアカウントで実際に支払う金額です。

### API トークンの作成と変更

- 作成、編集、有効化、無効化、削除の前には毎回、エージェントが送信する内容を示し、あなたの承認を待ちます。
- 特に指定しない限り、新しいトークンはコンソールと同じく、クォータ無制限・有効期限なしで作成されます。クォータ上限、有効期限、使用を許可するモデルの一覧を指定することもできます。
- トークンを作成すると、エージェントが完全なキーを一度だけ表示します。アプリや設定ファイルにコピーしてください。
- トークンの削除は元に戻せません。そのキーを使っているアプリはすぐに動かなくなります。

## Skill がしないこと

- API トークン以外は何も変更しません。支払い、チャージコードの引き換え、アカウントの編集は行いません。これらは [コンソール](https://aiberm.com/console) で行ってください。
- システムアクセストークンをリセットしません。Skill は、そのエンドポイントを決して呼び出さないようエージェントに指示しています。
- 既存の API トークンの完全なキーは表示しません。トークン一覧には完全なキーが含まれますが、エージェントは `sk-abcd****wxyz` のようにマスクして表示します。完全なキーは [トークン管理](https://aiberm.com/console/token) からコピーしてください。唯一の例外は、エージェントがたった今作成したトークンです。

<Callout client:load type="warning">
これらのルールはエージェントへの指示であり、技術的なロックではありません。このトークンでは、コンソールにログインしてできることがすべてできます。信頼できるエージェントとマシンでのみ使ってください。漏えいした場合は、アカウント設定で **再生成** を押してください。
</Callout>

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| エージェントに変数が設定されていないと言われる | 両方を設定し、新しいターミナルを開いてから、新しいエージェントセッションを開始してください。 |
| `未提供 New-Api-User` | `AIBERM_USER_ID` が設定されていません。 |
| `New-Api-User 与登录用户不匹配` | `AIBERM_USER_ID` が、トークンを所有するアカウントの ID ではありません。同じアカウントのアカウント設定から ID をコピーしてください。 |
| `access token 无效` | トークンが間違っているか、再生成されています。新しいトークンを生成し、`AIBERM_ACCESS_TOKEN` を更新してください。 |
| エージェントが Skill を使わない | 新しいセッションを開始してください。Claude Code では、`/plugin` で `aiberm` が有効になっていることを確認するか、`/aiberm:aiberm` と入力します。Codex では、`codex plugin list` で `aiberm@aiberm` がインストール済みになっていることを確認してください。 |
| `时间跨度不能超过 1 个月` | 時間別の使用量は、1 回のリクエストで最大 30 日分です。期間を短くして聞いてください。 |

Skill のソースとリクエストの完全な一覧は [aiberm-skill リポジトリ](https://github.com/aiberm/aiberm-skill) にあります。モデル API 自体のエラーについては、[エラー処理](/docs/ja/error-handling/) を参照してください。
