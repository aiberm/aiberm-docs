# Hermes Agent のセットアップ

このガイドでは、[Hermes Agent](https://hermes-agent.nousresearch.com/) を Aiberm をモデルプロバイダとして使うように設定する方法を説明します。Hermes Agent は Nous Research が開発したオープンソースの AI エージェントで、ターミナルで動作し、Telegram、Discord、Slack、WhatsApp、Signal などのメッセージングプラットフォームと連携できます。

Aiberm は OpenAI 互換の `/v1` API を公開しているため、プラグインのインストールやソースコードの変更なしに、Hermes Agent のカスタムプロバイダとして登録できます。設定後は、1 つの API キーで Aiberm 上のすべてのモデル（Claude、GPT、Gemini、DeepSeek、Kimi、MiniMax、GLM、Grok など）にアクセスできます。

## 前提条件

- Aiberm アカウント（[登録](https://aiberm.com/register)）
- Aiberm API キー（[キーを取得](https://aiberm.com/console/token)）
- Hermes Agent がインストール済みであること — [公式インストールガイド](https://hermes-agent.nousresearch.com/docs/getting-started/) を参照してください

クイックインストール（Linux / macOS / WSL2）:

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

## Aiberm をプロバイダとして設定する

Hermes Agent は設定を `~/.hermes/config.yaml` に保存します。ファイルを開き、`providers:` セクションに `aiberm` エントリを追加します。

> **Vim などのコマンドラインエディタに慣れていない場合**は、OS 標準のエディタで設定ファイルを開けます。
>
> - **macOS**: **Finder** を開き、`Shift + Command + G` を押し、表示されたダイアログに `~/.hermes` と入力して Return を押します。`config.yaml` を右クリックし、**Open With → TextEdit** を選びます。
> - **Windows**: **File Explorer** を開き、アドレスバーに `%USERPROFILE%\.hermes` と入力して Enter を押します。`config.yaml` を右クリックし、**Open with → Notepad** を選びます。
>
> 編集後は **ファイルを保存** し（macOS は `Command + S`、Windows は `Ctrl + S`）、下記の再起動手順に進んでください。

### フィールドリファレンス

| フィールド | 必須 | 説明 |
|-------|----------|-------------|
| `base_url` | はい | Aiberm の OpenAI 互換エンドポイント。`https://aiberm.com/v1` に設定します。 |
| `api_key` | はい | Aiberm API キー。[コンソール](https://aiberm.com/console/token) から取得できます。 |
| `type` | はい | プロトコルタイプ。`openai` に設定します。Aiberm は OpenAI Chat Completions 仕様に準拠しています。 |
| `default_model` | はい | 明示的なモデル指定がないときに使うモデルです。 |
| `models` | 推奨 | `/model` ピッカーに表示されるモデル一覧です。Hermes はこの一覧（および `default_model`）にあるエントリだけを表示します。省略すると、ピッカーはボタン 1 つだけを表示します。 |

トップレベルの `model:` セクションは、アクティブなプロバイダとデフォルトモデルを指定します。以前に別のプロバイダを使っていた場合は、`provider:` を `aiberm` に、`default:` を `models:` ブロック内のいずれかのモデルに設定してください。

## 使い方

設定を更新したら、Hermes を再起動します（CLI: 終了して `hermes` を再実行、gateway: `hermes gateway restart`）。

**ターミナル（CLI）の場合:**

```
/model
```

Hermes はインタラクティブなモデルピッカーを開きます。**Aiberm** を選び、目的のモデルを選択します。直接切り替えることもできます。

```
/model claude-opus-4-7
/model gpt-5.4 --global
```

`--global` を付けると変更が `config.yaml` に永続化されます。省略すると、現在のセッションにのみ適用されます。

**Telegram、Discord、Slack、WhatsApp の場合:**

ボットに `/model` を送信します。認証情報が設定されているすべてのプロバイダを一覧したインラインキーボードが返ります。**Aiberm** を選ぶと、ページ分割されたモデル一覧（1 ページ 8 件、Prev / Next で移動）が表示され、モデルをタップして切り替えられます。

![Telegram /model picker showing Aiberm's paginated model list](/docs/hermes-model-picker.png)

## 完全なモデルカタログを確認する

上記の `models:` 一覧は厳選したサブセットです。Aiberm が現在提供しているすべてのモデルを確認するには、API を直接クエリします。

```bash
curl -H "Authorization: Bearer sk-your-aiberm-api-key" \
     https://aiberm.com/v1/models | jq -r '.data[].id'
```

使いたいモデル ID を `models:` ブロックに追加し、Hermes を再起動します。すると `/model` ピッカーに表示されます。

## 環境変数を使う（任意）

API キーを `config.yaml` に保存したくない場合は、環境変数から読み取れます。次を設定します。

```bash
export AIBERM_API_KEY=sk-your-aiberm-api-key
```

その後、`config.yaml` で `key_env` 経由で参照します。

```yaml
providers:
  aiberm:
    base_url: https://aiberm.com/v1
    key_env: AIBERM_API_KEY
    type: openai
    default_model: claude-sonnet-4-6
```

## トラブルシューティング

### `/model` で Aiberm のボタンが 1 つしか表示されない

`providers.aiberm` ブロックに `models:` 一覧がありません。Hermes のピッカーは、8 件を超えるモデルが設定されているときだけページ分割します。上記の厳選リストを追加して Hermes を再起動してください。

### 401 Unauthorized

- [Aiberm コンソール](https://aiberm.com/console/token) で API キーを確認します。
- キーが設定ファイルのトップレベルではなく、`providers.aiberm.api_key` の下にあることを確認します。

### Model Not Found

Aiberm のモデルカタログは時間とともに変化します。一覧にあったモデルが改名または非推奨になっている場合があります。もう一度 `/v1/models` をクエリし（上記参照）、`models:` 一覧を更新してください。

### 設定が読み込まれているか確認する方法

```bash
hermes doctor
```

このコマンドは、現在アクティブなプロバイダとモデルを含む診断レポートを出力します。
