# Avvio rapido

Aiberm fornisce un'API unificata che ti dà accesso a centinaia di modelli di IA tramite un unico endpoint. Inizia in pochi minuti con il nostro processo di integrazione semplice.

<Callout client:load type="tip">
Cerchi informazioni sui modelli gratuiti e sui limiti di frequenza? Consulta le FAQ.
</Callout>

## Usare l'SDK OpenAI

Il modo più semplice è usare l'SDK ufficiale OpenAI: basta cambiare il base_url per iniziare a usarlo.

<CodeExample
  client:load
  examples={[
    {
      key: 'python',
      label: 'Python',
      code: `from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key-here",
    base_url="https://aiberm.com/v1"
)

response = client.chat.completions.create(
    model="google/gemini-2.5-flash",
    messages=[
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)`
    },
    {
      key: 'typescript',
      label: 'TypeScript',
      code: `import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: 'sk-your-api-key-here',
  baseURL: 'https://aiberm.com/v1'
});

const response = await openai.chat.completions.create({
  model: 'google/gemini-2.5-flash',
  messages: [
    { role: 'user', content: 'Hello!' }
  ]
});

console.log(response.choices[0].message.content);`
    }
  ]}
/>

## Usare direttamente l'API Aiberm

Puoi usare richieste HTTP per chiamare l'API direttamente.

<Callout client:load type="info">
Usa il nostro Request Builder interattivo per generare richieste API.
</Callout>

<CodeExample
  client:load
  examples={[
    {
      key: 'python',
      label: 'Python',
      code: `import requests

response = requests.post(
    "https://aiberm.com/v1/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={
        "model": "google/gemini-2.5-flash",
        "messages": [
            {"role": "user", "content": "Hello!"}
        ]
    }
)

print(response.json())`
    },
    {
      key: 'typescript',
      label: 'TypeScript',
      code: `const response = await fetch('https://aiberm.com/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    model: 'google/gemini-2.5-flash',
    messages: [{ role: 'user', content: 'Hello!' }]
  })
});

const data = await response.json();
console.log(data);`
    },
    {
      key: 'curl',
      label: 'Curl',
      code: `curl https://aiberm.com/v1/chat/completions \\
  -H "Content-Type: application/json" \\
  -H "Authorization: Bearer YOUR_API_KEY" \\
  -d '{
    "model": "google/gemini-2.5-flash",
    "messages": [
      {"role": "user", "content": "Hello!"}
    ]
  }'`
    }
  ]}
/>
