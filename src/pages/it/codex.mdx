# Configurazione di Codex CLI

Scopri come configurare Codex CLI per usare l'API di Aiberm. Questa guida copre l'installazione e la configurazione per Windows, macOS e Linux.

## Che cos'è Codex CLI?

Codex CLI è l'interfaccia a riga di comando di OpenAI progettata per attività di codice nel terminale. Privilegia un output pronto per l'ingegneria, con modifiche al codice più chiare e attuabili rispetto agli strumenti di chat generici. Configurandolo per usare Aiberm, puoi accedere a più modelli di IA tramite un endpoint conveniente.

## Prerequisiti

Prima di iniziare, assicurati di avere:

- Un account Aiberm ([Registrati qui](https://aiberm.com/register))
- Una API key Aiberm ([Ottieni la tua chiave](https://aiberm.com/console/token))
- Node.js v20 o superiore con npm

## Installazione

Installa Codex CLI a livello globale usando npm:

```bash
npm install -g @openai/codex
```

**Verifica l'installazione:**
```bash
codex --version
```

Dovrebbe essere visualizzato il numero di versione.

## Configurazione

Codex CLI usa un file `config.toml` per la configurazione. La directory di configurazione varia in base al sistema operativo:

- **Windows**: `%userprofile%\.codex`
- **macOS/Linux**: `~/.codex`

### Metodo 1: configurazione manuale

Vai alla directory di configurazione e crea o modifica `config.toml`:

**macOS/Linux:**
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```

**Windows:**
```powershell
mkdir $env:USERPROFILE\.codex -Force
notepad $env:USERPROFILE\.codex\config.toml
```

Aggiungi la seguente configurazione:

```toml
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.com/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
```

**Importante:** Sostituisci `sk-your-aiberm-api-key` con la tua vera API key Aiberm. La chiave viene salvata in testo semplice in `config.toml`. Non eseguire il commit di questo file in Git e non condividerlo con altri.

### Metodo 2: configurazione con un solo comando

**macOS/Linux:**
```bash
mkdir -p ~/.codex && cat > ~/.codex/config.toml << 'EOF'
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.com/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
EOF
```

**Windows PowerShell:**
```powershell
$configPath = "$env:USERPROFILE\.codex"
New-Item -ItemType Directory -Force -Path $configPath | Out-Null
@"
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.com/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
"@ | Out-File -FilePath "$configPath\config.toml" -Encoding utf8
```

**Importante:** Sostituisci `sk-your-aiberm-api-key` nella configurazione con la tua vera API key Aiberm. La chiave viene salvata in testo semplice in `config.toml`. Non eseguire il commit di questo file in Git e non condividerlo con altri.

## Verificare la configurazione

**Controlla l'installazione di Node.js:**
```bash
node -v
npm -v
```

**Verifica l'installazione di Codex CLI:**
```bash
codex --version
```

**Testa la connessione API:**
```bash
codex "Hi"
```

Se è configurato correttamente, Codex CLI dovrebbe rispondere usando l'API di Aiberm.

## Risoluzione dei problemi

### Errore 401 Unauthorized

- Verifica che la API key sia corretta: [Console → API Keys](https://aiberm.com/console/token)
- Assicurati che `experimental_bearer_token` contenga la tua vera API key Aiberm e che il segnaposto non sia stato salvato invariato

### Errore 403 Forbidden

- Controlla la validità della API key
- Verifica il saldo dell'account su [https://aiberm.com/console](https://aiberm.com/console)
- Assicurati che la API key abbia accesso al modello richiesto

### Errori di rete

- Verifica la connessione a Internet
- Controlla se puoi accedere a https://aiberm.com nel browser
- Assicurati che il firewall consenta le connessioni HTTPS in uscita
- Conferma che `base_url` in `config.toml` sia corretto: `https://aiberm.com/v1`

### La configurazione non ha effetto

- Riavvia il terminale dopo aver modificato `config.toml`
- Convalida la sintassi TOML (niente spazi extra, virgolette corrette)
- Controlla che la posizione del file di configurazione sia corretta per il tuo sistema operativo
- Assicurati che il file sia salvato come `config.toml` (non `config.toml.txt`)

### Comando Codex non trovato

**macOS/Linux:**
```bash
# Check if npm global bin is in PATH
npm config get prefix

# If needed, add to PATH in ~/.zshrc or ~/.bashrc:
export PATH="$(npm config get prefix)/bin:$PATH"
```

**Windows:**
- Verifica che il percorso globale di npm sia nel PATH di sistema
- Riavvia il terminale dopo l'installazione di npm
