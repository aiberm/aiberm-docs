# Embedding

Converti il testo in rappresentazioni vettoriali numeriche per ricerca semantica, clustering e raccomandazioni.

## Creare embedding

`POST https://aiberm.com/v1/embeddings`

<CodeExample
  client:load
  examples={[
    {
      key: 'python',
      label: 'Python',
      code: `from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://aiberm.com/v1"
)

response = client.embeddings.create(
    model="text-embedding-3-small",
    input="Your text here"
)

embedding = response.data[0].embedding
print(f"Embedding dimension: {len(embedding)}")`
    },
    {
      key: 'curl',
      label: 'cURL',
      code: `curl https://aiberm.com/v1/embeddings \\
  -H "Authorization: Bearer YOUR_API_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{
    "model": "text-embedding-3-small",
    "input": "Your text here"
  }'`
    }
  ]}
/>

<Callout client:load type="tip">
Usa gli embedding per ricerca semantica, similarità tra documenti e sistemi di raccomandazione.
</Callout>
