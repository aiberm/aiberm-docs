# FAQ

## Qual è la differenza tra i due set di modelli Claude su Aiberm?

Aiberm offre due set di modelli Claude per casi d'uso diversi:

- **Modelli con prefisso `claude-`**: Disponibili con uno sconto dell'81%, ideali per scenari di coding. Claude Code supporta di default i modelli con prefisso `claude-`.
- **Modelli con prefisso `anthropic/`**: Instradati tramite AWS, con circa il 28% di sconto sul prezzo ufficiale.

## I modelli Aiberm supportano la cache?

Sì, tutti i modelli Claude di Aiberm supportano il prompt caching. La cache è stata ottimizzata per un alto tasso di hit. Quando la cache viene colpita, il prezzo viene moltiplicato per 0,1. Anche altri modelli supportano la cache.
