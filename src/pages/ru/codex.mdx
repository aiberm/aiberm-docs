# Настройка Codex CLI

Узнайте, как настроить Codex CLI для работы с API Aiberm. В руководстве описаны установка и конфигурация для Windows, macOS и Linux.

## Что такое Codex CLI?

Codex CLI — интерфейс командной строки OpenAI для задач по коду в терминале. Он ориентирован на инженерный результат: изменения в коде более ясные и применимые, чем у обычных чат-инструментов. Настроив его на Aiberm, вы получите доступ к нескольким моделям ИИ через экономичный эндпоинт.

## Предварительные требования

Перед началом убедитесь, что у вас есть:

- Аккаунт Aiberm ([Зарегистрироваться](https://aiberm.com/register))
- API-ключ Aiberm ([Получить ключ](https://aiberm.com/console/token))
- Node.js v20 или новее вместе с npm

## Установка

Установите Codex CLI глобально через npm:

```bash
npm install -g @openai/codex
```

**Проверка установки:**
```bash
codex --version
```

Должен отобразиться номер версии.

## Настройка

Codex CLI использует файл `config.toml`. Расположение каталога конфигурации зависит от ОС:

- **Windows**: `%userprofile%\.codex`
- **macOS/Linux**: `~/.codex`

### Способ 1: ручная настройка

Перейдите в каталог конфигурации и создайте или отредактируйте `config.toml`:

**macOS/Linux:**
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```

**Windows:**
```powershell
mkdir $env:USERPROFILE\.codex -Force
notepad $env:USERPROFILE\.codex\config.toml
```

Добавьте следующую конфигурацию:

```toml
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.org/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
```

**Важно:** замените `sk-your-aiberm-api-key` на настоящий API-ключ Aiberm. Ключ хранится в открытом виде в `config.toml`. Не добавляйте этот файл в Git и не делитесь им с другими.

### Способ 2: настройка одной командой

**macOS/Linux:**
```bash
mkdir -p ~/.codex && cat > ~/.codex/config.toml << 'EOF'
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.org/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
EOF
```

**Windows PowerShell:**
```powershell
$configPath = "$env:USERPROFILE\.codex"
New-Item -ItemType Directory -Force -Path $configPath | Out-Null
@"
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.org/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
"@ | Out-File -FilePath "$configPath\config.toml" -Encoding utf8
```

**Важно:** замените `sk-your-aiberm-api-key` в конфигурации на настоящий API-ключ Aiberm. Ключ хранится в открытом виде в `config.toml`. Не добавляйте этот файл в Git и не делитесь им с другими.

## Проверка конфигурации

**Проверка установки Node.js:**
```bash
node -v
npm -v
```

**Проверка установки Codex CLI:**
```bash
codex --version
```

**Проверка подключения к API:**
```bash
codex "Hi"
```

Если всё настроено правильно, Codex CLI ответит через API Aiberm.

## Устранение неполадок

### Ошибка 401 Unauthorized

- Проверьте правильность API-ключа: [Консоль → API Keys](https://aiberm.com/console/token)
- Убедитесь, что `experimental_bearer_token` содержит настоящий API-ключ Aiberm, а placeholder не сохранён без изменений

### Ошибка 403 Forbidden

- Проверьте действительность API-ключа
- Проверьте баланс аккаунта на [https://aiberm.com/console](https://aiberm.com/console)
- Убедитесь, что у ключа есть доступ к запрошенной модели

### Сетевые ошибки

- Проверьте подключение к интернету
- Убедитесь, что https://aiberm.com открывается в браузере
- Проверьте, что брандмауэр разрешает исходящие HTTPS-соединения
- Убедитесь, что `base_url` в `config.toml` указан верно: `https://aiberm.org/v1`

### Конфигурация не применяется

- Перезапустите терминал после правки `config.toml`
- Проверьте синтаксис TOML (без лишних пробелов, корректные кавычки)
- Убедитесь, что путь к файлу конфигурации соответствует вашей ОС
- Убедитесь, что файл сохранён как `config.toml` (не `config.toml.txt`)

### Команда Codex не найдена

**macOS/Linux:**
```bash
# Check if npm global bin is in PATH
npm config get prefix

# If needed, add to PATH in ~/.zshrc or ~/.bashrc:
export PATH="$(npm config get prefix)/bin:$PATH"
```

**Windows:**
- Убедитесь, что глобальный путь npm добавлен в системный PATH
- Перезапустите терминал после установки npm
