# Список моделей

Получите список всех моделей ИИ, доступных текущему пользователю, включая ID, названия, провайдеров и подробную информацию.

<Callout client:load type="info" title="О списке моделей и группах токенов">
Модели в списке зависят от группы токена, к которой относится ваш API KEY. Группу токена можно выбрать при создании или редактировании токенов в Консоль → API Tokens.
</Callout>

## Эндпоинт

`GET https://aiberm.com/v1/models`

## Поля ответа

**Поля верхнего уровня:**
- `success` — логическое значение, показывает, успешен ли запрос
- `data` — массив объектов моделей (только при успехе)
- `message` — сообщение об ошибке (только при неудаче)

**Поля объекта модели:**
- `id` — уникальный идентификатор модели
- `object` — тип объекта, всегда `"model"`
- `created` — метка времени создания модели
- `owned_by` — провайдер модели (например, openai, anthropic)
- `supported_endpoint_types` — массив поддерживаемых типов эндпоинтов API

## Поддерживаемые типы эндпоинтов

- `chat` — Chat Completion
- `completion` — Text Completion
- `embedding` — Text Embedding
- `image` — генерация изображений
- `audio` — обработка аудио
- `rerank` — Rerank

## Важные замечания

<Callout client:load type="info" title="Требуется аутентификация">
Необходимо указать действительный API-токен. Токен определяет, какие модели доступны пользователю.
</Callout>

<Callout client:load type="info" title="Контроль доступа">
Список моделей фильтруется по группам пользователей и токенов: отображаются только модели, к которым у пользователя есть доступ.
</Callout>

## Типичные ошибки

- `401 Unauthorized` — API-токен недействителен или истёк
- `403 Forbidden` — у пользователя нет прав доступа
- `500 Internal Server Error` — внутренняя ошибка сервера
