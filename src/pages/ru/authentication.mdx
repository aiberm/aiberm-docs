# Аутентификация

Все запросы к API требуют аутентификации. Мы используем Bearer Token, чтобы ваши вызовы API были безопасными и надёжными.

## Получение API-ключа

Перейдите в Консоль → API Tokens, чтобы создать и управлять ключами API.

<Callout client:load type="info" title="Шаги создания">
1. Войдите в аккаунт Aiberm
2. Откройте страницу Консоли
3. В левом меню нажмите «API Tokens»
4. Нажмите кнопку «New Token»
5. Задайте имя токена и права доступа
6. Скопируйте сгенерированный API-ключ
</Callout>

## Замечания по безопасности

- Храните API-ключ в секрете и не раскрывайте его в клиентском коде
- Регулярно ротируйте API-ключи, чтобы повысить безопасность аккаунта
- Если ключ утечёт, сразу удалите его в консоли и сгенерируйте новый
- Храните API-ключи в переменных окружения, а не вшивайте их в код

## Типичные ошибки

<Callout client:load type="error" title="401 Unauthorized">
Недействительный или истёкший API-ключ

**Решение:** Проверьте правильность ключа или сгенерируйте новый
</Callout>

<Callout client:load type="error" title="403 Forbidden">
Недостаточно прав или аккаунт ограничен

**Решение:** Проверьте статус аккаунта и обратитесь к администратору за нужными правами
</Callout>
