# Часто задаваемые вопросы

## Чем отличаются два набора моделей Claude на Aiberm?

Aiberm предлагает два набора моделей Claude для разных сценариев:

- **Модели с префиксом `claude-`**: доступны со скидкой 81%, лучше всего подходят для задач программирования. Claude Code по умолчанию поддерживает модели с префиксом `claude-`.
- **Модели с префиксом `anthropic/`**: маршрутизируются через AWS, примерно на 28% дешевле официальной цены.

## Поддерживают ли модели Aiberm кэширование?

Да, все модели Claude на Aiberm поддерживают prompt caching. Кэш оптимизирован для высокой доли попаданий. При попадании в кэш цена умножается на 0.1. Другие модели также поддерживают кэширование.


## Как получить Invoice?

- **Самостоятельный Invoice**: [https://meiguo.app/invoice](https://meiguo.app/invoice)
- **Счета при корпоративном банковском переводе** доступны — свяжитесь с администратором группы @Folyd
- **Для некорпоративных переводов** минимальная сумма для китайского фапяо (Fapiao) составляет $500. При сумме ниже $500 взимается дополнительный налоговый сбор 8%.
