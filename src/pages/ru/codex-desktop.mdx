# Настройка Codex Desktop

Десктопное приложение OpenAI Codex может войти по API-ключу и открыть пользовательский `config.toml` изнутри приложения. После настройки Aiberm Codex отправляет запросы через Responses-совместимый эндпоинт Aiberm.

<Callout client:load type="info">
Поле входа по-прежнему подписано как OpenAI API key. Введите туда свой API-ключ Aiberm, например `sk-...`.
</Callout>

## Предварительные требования

Перед началом убедитесь, что у вас есть:

- Последняя версия десктопного приложения OpenAI Codex
- Аккаунт Aiberm ([Регистрация](https://aiberm.com/register))
- API-ключ Aiberm ([Создать в Консоли](https://aiberm.com/console/token))

## Настройка

1. Откройте десктопное приложение Codex.
2. На экране входа выберите **Sign in another way**.

![Choose another sign-in method in Codex Desktop](/docs/codex-desktop/codex-signin.png)

3. Введите API-ключ Aiberm в поле **OpenAI API key** и нажмите **Continue**.

![Enter an API key in Codex Desktop](/docs/codex-desktop/codex-signin-with-apikey.png)

> Примечание: этот шаг позволяет только войти в десктопное приложение Codex. Он не заменяет настройку API-ключа в `config.toml`. Выполните приведённую ниже настройку, даже если вы уже ввели ключ на экране входа.

4. После входа в приложение откройте Settings.
5. В боковой панели выберите **Configuration**.
6. В разделе **Custom config.toml settings** убедитесь, что выбран **User config**.
7. Нажмите **Open config.toml**, чтобы открыть пользовательский файл конфигурации.

![Open config.toml in Codex Desktop](/docs/codex-desktop/codex-configuration.png)

8. Добавьте или замените содержимое `config.toml` на:

```toml
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.org/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
```

Замените `sk-your-aiberm-api-key` на настоящий API-ключ Aiberm. Ключ хранится на компьютере в открытом виде. Не добавляйте этот файл в Git и не делитесь им с другими.

9. Сохраните `config.toml`.
10. Полностью закройте и снова откройте десктопное приложение Codex.

## Проверка работы

После повторного открытия Codex:

1. Откройте проект или рабочее пространство.
2. Попросите Codex выполнить реальную задачу по коду: объяснить текущий файл, отредактировать небольшой фрагмент или запустить тесты проекта.

Если задача выполняется и возвращает результат, конфигурация работает.

## Устранение неполадок

### Недействительный API Key

- Скопируйте полный ключ из [Консоли Aiberm](https://aiberm.com/console/token).
- Проверьте, нет ли лишних пробелов до или после ключа.
- Убедитесь, что ключ начинается с `sk-`.

### Изменения конфигурации не применяются

- Убедитесь, что вы редактировали `config.toml`, открытый из **User config**.
- Полностью закройте и снова откройте десктопное приложение Codex после сохранения файла.
- Убедитесь, что `model_provider = "aiberm"` соответствует `[model_providers.aiberm]`.
- Убедитесь, что `experimental_bearer_token` заменён на настоящий API-ключ Aiberm, а placeholder не сохранён без изменений.

### Ошибки модели или подключения

- Убедитесь, что `base_url` точно равен `https://aiberm.org/v1`.
- Убедитесь, что `wire_api` равен `responses`.
- Убедитесь, что у аккаунта есть доступ к `gpt-5.6-sol`. Актуальный список см. в [Списке моделей](/docs/ru/models).
