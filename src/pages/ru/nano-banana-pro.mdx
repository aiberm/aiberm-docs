# NanoBanana Pro

NanoBanana Pro — сервис генерации изображений Gemini. Он поддерживает несколько соотношений сторон (1:1, 16:9, 9:16 и др.) и разрешений (1K, 2K, 4K). Цена у всех разрешений одинаковая; 4K генерируется медленнее и не рекомендуется. См. [Pricing](/pricing?tab=gemini).

**Эндпоинт**: `POST https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent`

**Главное**: отправьте описание изображения в теле запроса `contents`; задайте `responseModalities` и `imageConfig` (соотношение сторон, разрешение) в `generationConfig`. Сгенерированное изображение находится в `candidates[0].content.parts` как `inline_data`.

## Пример кода

В Python используется snake_case (например, `response_modalities`); в REST/cURL — camelCase (например, `responseModalities`). Смысл тот же.

### Параметры изображения в cURL

Ниже имена параметров (camelCase) для cURL; в Python используйте snake_case (например, `aspectRatio` → `aspect_ratio`).

**imageConfig** (`generationConfig.imageConfig` или SDK `ImageConfig`):

- **aspectRatio** `string` — `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`
- **imageSize** `string` — `1K`, `2K`, `4K` (только gemini-3-pro-image-preview)

**Другие часто используемые поля generationConfig:**

- **responseModalities** `string[]` — `["IMAGE"]` или `["TEXT", "IMAGE"]`
- **temperature** `number` — 0–2, выше — более случайный результат
- **topP** `number` — 0–1, разнообразие
- **maxOutputTokens** `number` — например, 8192
- **systemInstruction** `object` — например, `{"parts": [{"text": "..."}]}`
- **tools** `array` — например, `[{"google_search": {}}]`

## Включение Google Search

Google Search поддерживается только в Gemini-стиле API. Передайте `tools` в конфигурации; модель при необходимости будет использовать актуальную информацию из сети.

**По умолчанию не рекомендуется:** увеличивает задержку и стоимость; для чисто графических задач не нужно. Отключите, если поиск не требуется.

**Python (SDK):**

```python
config = types.GenerateContentConfig(
    # ... other params like response_modalities, image_config
    tools=[{"google_search": {}}]
)
response = client.models.generate_content(model=model, contents=[prompt], config=config)
```

**cURL (REST):**

Добавьте `tools` на верхнем уровне тела запроса:

```bash
curl -X POST "https://aiberm.com/v1beta/models/gemini-3-pro-image-preview:generateContent" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "Your question"}]}],
    "generationConfig": { ... },
    "tools": [{"google_search": {}}]
  }'
```

## FAQ

- **В ответе нет изображения:** убедитесь, что модель — `gemini-3-pro-image-preview`, а промпт — ясное описание изображения.
- **Ошибка декодирования:** используйте только строку base64 после `data:image/...;base64,` и удалите переносы строк перед декодированием.
