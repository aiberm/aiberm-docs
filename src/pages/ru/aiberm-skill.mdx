# Навык Aiberm для агентов

[aiberm-skill](https://github.com/aiberm/aiberm-skill) учит агента для программирования читать данные вашего собственного аккаунта Aiberm. После установки можно спросить Claude Code, Codex или другого агента: «Сколько у меня осталось на балансе Aiberm?» Агент сам обратится к API Aiberm и ответит простыми словами.

Навык показывает баланс, группы, модели, цены, API-токены, журналы использования и историю пополнений. Ещё он умеет создавать, изменять, включать, отключать и удалять ваши API-токены и перед каждым изменением спрашивает вашего подтверждения.

<Callout client:load type="info">
Навык — это папка с файлом `SKILL.md`. Когда ваш вопрос подходит под описание навыка, агент читает этот файл и сам запускает `curl`. Ничего не работает в фоне, ничего не нужно собирать или держать запущенным.
</Callout>

## Предварительные требования

- Аккаунт Aiberm ([зарегистрироваться](https://aiberm.com/register))
- Агент с поддержкой навыков, например [Claude Code](/docs/ru/claude-code/) или [Codex](/docs/ru/codex/)
- `curl` и bash-совместимая оболочка. В macOS и Linux есть и то и другое. В Windows Claude Code использует Git Bash.

## 1. Получите ID пользователя и токен доступа к системе

Навыку нужны два значения. Оба находятся на странице [Личные настройки](https://aiberm.com/console/personal):

| Значение | Где найти |
| --- | --- |
| ID пользователя | В шапке вверху страницы, в виде `ID: 123` |
| Токен доступа к системе | Вкладка **Настройки безопасности** → **Токен доступа к системе** → **Сгенерировать токен** |

Aiberm проверяет оба значения при каждом запросе к аккаунту. ID должен принадлежать тому же аккаунту, что и токен.

<Callout client:load type="warning">
Токен доступа к системе — **не** API-ключ (`sk-...`). Он работает как вход в консоль: любой, у кого он есть, может делать в консоли всё то же, что и вы. Храните его в секрете. Кнопка **Сгенерировать заново** заменяет токен, и всё, что ещё использует старый, перестаёт работать.
</Callout>

## 2. Установите навык

Скопируйте папку `skills/aiberm` из репозитория в папку навыков вашего агента:

```bash
git clone https://github.com/aiberm/aiberm-skill.git
mkdir -p ~/.claude/skills
cp -R aiberm-skill/skills/aiberm ~/.claude/skills/aiberm
```

| Агент | Папка навыков |
| --- | --- |
| Claude Code | `~/.claude/skills/aiberm` для всех проектов или `.claude/skills/aiberm` внутри одного проекта |
| Codex | `~/.codex/skills/aiberm` |
| Cursor | `~/.cursor/skills/aiberm` |

Для других агентов положите папку `aiberm` туда, откуда агент загружает навыки. Чтобы потом обновить навык, выполните `git pull` в клонированном репозитории и скопируйте папку заново.

## 3. Задайте две переменные

Агент берёт значения из переменных окружения, поэтому задайте их до запуска агента.

**macOS / Linux**: добавьте эти строки в `~/.zshrc` или `~/.bashrc`, затем откройте новый терминал:

```bash
export AIBERM_ACCESS_TOKEN="ваш-токен-доступа-к-системе"
export AIBERM_USER_ID="123"
```

**Windows (PowerShell)**: выполните команды ниже, затем откройте новый терминал:

```powershell
setx AIBERM_ACCESS_TOKEN "ваш-токен-доступа-к-системе"
setx AIBERM_USER_ID "123"
```

<Callout client:load type="tip">
Только для Claude Code: вместо этого обе переменные можно указать в блоке `env` файла `~/.claude/settings.json`.
</Callout>

Чтобы проверить значения ещё до подключения агента, запросите свой профиль. `data.quota`, делённое на 500000, — это остаток баланса в долларах США.

```bash
curl -sS "https://aiberm.com/api/user/self" \
  -H "Authorization: Bearer $AIBERM_ACCESS_TOKEN" \
  -H "New-Api-User: $AIBERM_USER_ID"
```

## 4. Спросите агента

Начните новый сеанс агента и спросите своими словами:

- «Сколько у меня осталось на балансе Aiberm?»
- «Сколько я вчера потратил в Aiberm? Разбей по моделям.»
- «Покажи мои API-токены Aiberm и сколько квоты осталось у каждого.»
- «Сколько стоит `claude-sonnet-5-5` за 1M токенов в моей группе?»
- «Какими моделями в Aiberm я больше всего пользовался на этой неделе?»
- «Покажи мои последние пополнения в Aiberm.»
- «Создай API-ключ Aiberm с именем `my-app` и лимитом $5.»
- «Отключи мой токен Aiberm `old-test`.»

В Claude Code навык можно также вызвать напрямую командой `/aiberm`.

| О чём вы спрашиваете | Что читает навык |
| --- | --- |
| Баланс и общие расходы | `GET /api/user/self` |
| Группы и их ценовые коэффициенты | `GET /api/user/self/groups` |
| Модели, которые вам доступны | `GET /api/user/models` |
| Цены моделей | `GET /api/pricing` |
| API-токены | `GET /api/token/` |
| Журналы использования | `GET /api/log/self` |
| Сводка по использованию | `GET /api/log/self/stat` |
| Использование по часам и моделям | `GET /api/data/self` |
| История пополнений | `GET /api/user/topup/self` |
| Создание, изменение или удаление API-токенов | `POST`, `PUT` или `DELETE /api/token/` |

Суммы пересчитываются в доллары США по курсу 500000 квоты = $1. Цены считаются по коэффициентам групп вашего аккаунта, а не по публичным значениям по умолчанию.

### Создание и изменение API-токенов

- Перед каждым созданием, изменением, включением, отключением или удалением агент сообщает, что именно отправит, и ждёт вашего подтверждения.
- Если не попросить иначе, новый токен создаётся с неограниченной квотой и без срока действия, как в консоли. Можно попросить лимит расходов, срок действия, группу или список разрешённых моделей.
- После создания токена агент один раз показывает его полный ключ. Скопируйте его в своё приложение или конфигурацию.
- Удаление токена нельзя отменить, а приложения, которые используют его ключ, сразу перестают работать.

## Чего навык не делает

- Помимо API-токенов, он ничего не меняет. Не проводит платежи, не активирует коды пополнения и не редактирует аккаунт. Для этого используйте [консоль](https://aiberm.com/console).
- Он не сбрасывает токен доступа к системе. Навык запрещает агенту обращаться к этому маршруту.
- Он не раскрывает полные ключи ваших существующих API-токенов. Список токенов содержит полные ключи, но агент показывает их в замаскированном виде, например `sk-abcd****wxyz`. Полный ключ можно скопировать в разделе [Управление токенами](https://aiberm.com/console/token). Единственное исключение — токен, который агент только что создал для вас.

<Callout client:load type="warning">
Эти правила — инструкции для агента, а не техническая блокировка. Токен даёт всё, что даёт ваш вход в консоль. Используйте его только с агентами и на компьютерах, которым доверяете. Если токен утёк, нажмите **Сгенерировать заново** на странице «Личные настройки».
</Callout>

## Устранение неполадок

| Что вы видите | Что делать |
| --- | --- |
| Агент сообщает, что переменные не заданы | Задайте обе, откройте новый терминал и начните новый сеанс агента. |
| `未提供 New-Api-User` | Не задана переменная `AIBERM_USER_ID`. |
| `New-Api-User 与登录用户不匹配` | `AIBERM_USER_ID` не совпадает с ID аккаунта, которому принадлежит токен. Скопируйте ID на странице «Личные настройки» того же аккаунта. |
| `access token 无效` | Токен неверный или был сгенерирован заново. Сгенерируйте новый и обновите `AIBERM_ACCESS_TOKEN`. |
| Агент не использует навык | Проверьте, что файл лежит по пути `~/.claude/skills/aiberm/SKILL.md` (или в папке вашего агента), и начните новый сеанс. В Claude Code введите `/aiberm`. |
| `时间跨度不能超过 1 个月` | Почасовая статистика охватывает не больше 30 дней за один запрос. Запросите период покороче. |

Исходный код навыка и полный список запросов — в [репозитории aiberm-skill](https://github.com/aiberm/aiberm-skill). Ошибки самого API моделей описаны в разделе [Обработка ошибок](/docs/ru/error-handling/).
