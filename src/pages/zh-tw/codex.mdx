# Codex CLI 設定

了解如何設定 Codex CLI 以使用 Aiberm 的 API。本指南涵蓋 Windows、macOS 和 Linux 的安裝與設定。

## 什麼是 Codex CLI？

Codex CLI 是 OpenAI 的命令列介面，專為與程式碼相關的終端機任務而設計。與通用聊天工具相比，它強調工程就緒的輸出，提供更清晰、可執行的程式碼變更。透過設定它使用 Aiberm，您可以透過具成本效益的端點存取多個 AI 模型。

## 前置條件

開始之前，請確認您具備：

- 一個 Aiberm 帳戶（[在此註冊](https://aiberm.com/register)）
- 一個 Aiberm API 金鑰（[取得金鑰](https://aiberm.com/console/token)）
- Node.js v20 或更高版本及 npm

## 安裝

使用 npm 全域安裝 Codex CLI：

```bash
npm install -g @openai/codex
```

**驗證安裝：**
```bash
codex --version
```

這應該會顯示版本號。

## 設定

Codex CLI 使用 `config.toml` 檔案進行設定。設定目錄位置因作業系統而異：

- **Windows**：`%userprofile%\.codex`
- **macOS/Linux**：`~/.codex`

### 方法 1：手動設定

前往設定目錄並建立或編輯 `config.toml`：

**macOS/Linux：**
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```

**Windows：**
```powershell
mkdir $env:USERPROFILE\.codex -Force
notepad $env:USERPROFILE\.codex\config.toml
```

加入以下設定：

```toml
model = "gpt-5.4"
model_reasoning_effort = "medium"
model_provider = "aiberm"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.com/v1"
env_key = "OPENAI_API_KEY"  # 這是指環境變數的名稱
wire_api = "responses"
```

**注意：** `env_key` 設定告訴 Codex CLI 要讀取哪個環境變數。您將在下一步中，在此變數裡設定您的 Aiberm API 金鑰。

### 方法 2：一鍵設定

**macOS/Linux：**
```bash
mkdir -p ~/.codex && cat > ~/.codex/config.toml << 'EOF'
model = "gpt-5.4"
model_reasoning_effort = "medium"
model_provider = "aiberm"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.com/v1"
env_key = "OPENAI_API_KEY"  # 這是指環境變數的名稱
wire_api = "responses"
EOF
```

**Windows PowerShell：**
```powershell
$configPath = "$env:USERPROFILE\.codex"
New-Item -ItemType Directory -Force -Path $configPath | Out-Null
@"
model = "gpt-5.4"
model_reasoning_effort = "medium"
model_provider = "aiberm"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.com/v1"
env_key = "OPENAI_API_KEY"
wire_api = "responses"
"@ | Out-File -FilePath "$configPath\config.toml" -Encoding utf8
```

**注意：** 上述設定會讓 Codex CLI 從 `OPENAI_API_KEY` 環境變數讀取您的 API 金鑰，您將在下一步中使用 Aiberm API 金鑰設定該變數。

## 設定 API 金鑰

設定 TOML 檔案後，將您的 Aiberm API 金鑰設為環境變數。

**重要提示：** 儘管變數名為 `OPENAI_API_KEY`，您應該使用您的 **Aiberm API 金鑰**（而不是 OpenAI 金鑰）。Codex CLI 使用此標準變數名稱以維持相容性。

### 暫時（僅目前工作階段）

**macOS/Linux：**
```bash
export OPENAI_API_KEY="sk-your-aiberm-api-key"
```

**Windows PowerShell：**
```powershell
$env:OPENAI_API_KEY="sk-your-aiberm-api-key"
```

**Windows 命令提示字元：**
```cmd
set OPENAI_API_KEY=sk-your-aiberm-api-key
```

### 永久設定

**macOS/Linux (Bash)：**

加入 `~/.bashrc` 或 `~/.bash_profile`：
```bash
export OPENAI_API_KEY="sk-your-aiberm-api-key"
```

套用變更：
```bash
source ~/.bashrc  # 或 source ~/.bash_profile
```

**macOS/Linux (Zsh)：**

加入 `~/.zshrc`：
```bash
export OPENAI_API_KEY="sk-your-aiberm-api-key"
```

套用變更：
```bash
source ~/.zshrc
```

**Windows PowerShell：**
```powershell
[System.Environment]::SetEnvironmentVariable('OPENAI_API_KEY', 'sk-your-aiberm-api-key', 'User')
```

**Windows 命令提示字元：**
```cmd
setx OPENAI_API_KEY "sk-your-aiberm-api-key"
```

## 驗證設定

**檢查 Node.js 安裝：**
```bash
node -v
npm -v
```

**驗證 Codex CLI 安裝：**
```bash
codex --version
```

**測試 API 連線：**
```bash
codex "Hi"
```

**檢查環境變數：**

**macOS/Linux：**
```bash
echo $OPENAI_API_KEY
```

**Windows PowerShell：**
```powershell
echo $env:OPENAI_API_KEY
```

如果設定正確，Codex CLI 應該使用 Aiberm 的 API 進行回應。

## 疑難排解

### 401 未授權錯誤

- 驗證您的 API 金鑰是否正確：[控制台 → API 金鑰](https://aiberm.com/console/token)
- 確認 `OPENAI_API_KEY` 環境變數設定正確
- 設定環境變數後重新啟動終端機

### 403 禁止存取錯誤

- 檢查您的 API 金鑰是否有效
- 在 [https://aiberm.com/console](https://aiberm.com/console) 確認您的帳戶餘額
- 確認您的 API 金鑰可以存取所請求的模型

### 網路錯誤

- 驗證您的網際網路連線
- 檢查您是否可以在瀏覽器中存取 https://aiberm.com
- 確認您的防火牆允許對外 HTTPS 連線
- 確認 `config.toml` 中的 `base_url` 正確：`https://aiberm.com/v1`

### 設定未生效

- 編輯 `config.toml` 後重新啟動終端機
- 驗證 TOML 語法格式（沒有多餘空白，引號正確）
- 檢查設定檔位置對您的作業系統是否正確
- 確認檔案儲存為 `config.toml`（而不是 `config.toml.txt`）

### 找不到 Codex 命令

**macOS/Linux：**
```bash
# 檢查 npm 全域 bin 是否在 PATH 中
npm config get prefix

# 如果需要，在 ~/.zshrc 或 ~/.bashrc 中加入 PATH：
export PATH="$(npm config get prefix)/bin:$PATH"
```

**Windows：**
- 驗證 npm 全域路徑是否在系統 PATH 中
- npm 安裝後重新啟動終端機
