# 常見問題


## Aiberm 在中國大陸需要代理才能連線嗎？

Aiberm 不需要代理就能連線。

## Aiberm 的兩套 Claude 模型有什麼區別？

Aiberm 提供兩套 Claude 模型，適用於不同的使用情境：

- **`claude-` 開頭的模型**：1.9 折優惠價，最適合 Coding 情境。Claude Code 預設支援 `claude-` 開頭的模型。
- **`anthropic/` 開頭的模型**：走 AWS 通道，官方約 7.2 折。

## Aiberm 的模型支援快取嗎？

支援。Aiberm Claude 全系列支援快取，快取命中有經過調校，命中快取後價格乘以 0.1，其他模型同樣支援快取。

## Aiberm 是什麼匯率？

Aiberm 跟其他平台不一樣，不玩匯率遊戲，儲值是正常匯率 7，消費時是折扣價。

## 如何開立 Invoice / 發票？

- **自助開 Invoice**：[https://meiguo.app/invoice](https://meiguo.app/invoice)
- **對公轉帳**可開發票，請聯繫群主 @Folyd
- **非對公轉帳**需滿 $500 才可開發票，低於 $500 需補 8% 稅點
