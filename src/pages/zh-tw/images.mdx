# 圖像

aiberm 目前支援以下圖像相關能力，請點選對應頁面查看使用說明與接入方式。

## 圖像產生

**[GPT Image 2](/docs/zh-tw/gpt-image-2/)** — 透過 OpenAI 相容圖像介面產生與編輯圖片。

**[NanoBanana Pro](/docs/zh-tw/nano-banana-pro/)** — 根據文字描述產生圖像。

## 圖像編輯

**[GPT Image 2](/docs/zh-tw/gpt-image-2/)** — 支援參考圖、遮罩編輯與串流局部圖片。

**[NanoBananaPro Edit](/docs/zh-tw/nano-banana-pro-edit/)** — 在既有圖像基礎上進行編輯與修改。
