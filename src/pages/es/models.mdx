# Lista de modelos

Obtén una lista de todos los modelos de IA accesibles para el usuario actual, incluidos IDs, nombres, proveedores e información detallada.

<Callout client:load type="info" title="Acerca de la lista de modelos y los grupos de tokens">
Los modelos que se devuelven en la lista dependen del grupo de tokens al que pertenece tu API KEY. Puedes seleccionar el grupo de tokens al crear o editar tokens en Consola → API Tokens.
</Callout>

## Endpoint

`GET https://aiberm.com/v1/models`

## Campos de la respuesta

**Campos de nivel superior:**
- `success` - Booleano, indica si la solicitud se realizó correctamente
- `data` - Arreglo de objetos de modelo (se devuelve solo si hay éxito)
- `message` - Mensaje de error (se devuelve solo si hay un fallo)

**Campos del objeto de modelo:**
- `id` - Identificador único del modelo
- `object` - Tipo de objeto, fijo como "model"
- `created` - Marca de tiempo de creación del modelo
- `owned_by` - Proveedor del modelo (p. ej., openai, anthropic)
- `supported_endpoint_types` - Arreglo de tipos de endpoint de API compatibles

## Tipos de endpoint compatibles

- `chat` - Completación de chat
- `completion` - Completación de texto
- `embedding` - Embedding de texto
- `image` - Generación de imágenes
- `audio` - Procesamiento de audio
- `rerank` - Reordenamiento

## Notas importantes

<Callout client:load type="info" title="Se requiere autenticación">
Debes proporcionar un token de API válido. El token determina a qué modelos puede acceder el usuario.
</Callout>

<Callout client:load type="info" title="Control de permisos">
La lista de modelos devuelta se filtra según los grupos de usuarios y de tokens, y muestra solo los modelos a los que el usuario tiene permiso de acceso.
</Callout>

## Errores comunes

- `401 Unauthorized` - El token de API no es válido o está vencido
- `403 Forbidden` - El usuario no tiene permiso de acceso
- `500 Internal Server Error` - Error interno del servidor
