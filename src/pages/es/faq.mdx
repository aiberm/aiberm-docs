# Preguntas frecuentes

## ¿Cuál es la diferencia entre los dos conjuntos de modelos Claude en Aiberm?

Aiberm ofrece dos conjuntos de modelos Claude para distintos casos de uso:

- **Modelos con prefijo `claude-`**: Disponibles con un 81 % de descuento, ideales para escenarios de programación. Claude Code admite de forma predeterminada los modelos con prefijo `claude-`.
- **Modelos con prefijo `anthropic/`**: Se enrutan a través de AWS, con aproximadamente un 28 % de descuento respecto al precio oficial.

## ¿Los modelos de Aiberm admiten caché?

Sí, todos los modelos Claude de Aiberm admiten prompt caching. La caché está optimizada para tasas de acierto altas. Cuando hay un acierto de caché, el precio se multiplica por 0.1. Otros modelos también admiten caché.


## ¿Cómo obtengo una factura?

- **Factura de autoservicio**: [https://meiguo.app/invoice](https://meiguo.app/invoice)
- Hay facturas por **transferencia bancaria corporativa** — contacta al administrador del grupo @Folyd
- Las **transferencias no corporativas** requieren un mínimo de $500 para Fapiao china. Por debajo de $500 se aplica un recargo fiscal adicional del 8 %.
