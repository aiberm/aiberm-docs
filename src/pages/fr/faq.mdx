# FAQ

## Quelle est la différence entre les deux ensembles de modèles Claude sur Aiberm ?

Aiberm propose deux ensembles de modèles Claude pour des cas d'usage différents :

- **Modèles préfixés par `claude-`** : disponibles avec 81 % de réduction, particulièrement adaptés au coding. Claude Code prend en charge par défaut les modèles préfixés par `claude-`.
- **Modèles préfixés par `anthropic/`** : routés via AWS, environ 28 % moins chers que le tarif officiel.

## Les modèles Aiberm prennent-ils en charge le cache ?

Oui, tous les modèles Claude d'Aiberm prennent en charge le prompt caching. Le cache est optimisé pour un taux de hit élevé. En cas de hit, le prix est multiplié par 0.1. Les autres modèles prennent également en charge le cache.

## Comment obtenir une facture ?

- **Facture en libre-service** : [https://meiguo.app/invoice](https://meiguo.app/invoice)
- Les factures par **virement bancaire d'entreprise** sont disponibles — contactez l'administrateur du groupe @Folyd
- Les **virements non professionnels** nécessitent un minimum de 500 $ pour une Fapiao chinoise. En dessous de 500 $, une majoration fiscale de 8 % s'applique.
