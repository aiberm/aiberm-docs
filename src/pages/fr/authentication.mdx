# Authentification

Toutes les requêtes API nécessitent une authentification. Nous utilisons l’authentification par jeton Bearer pour garantir que vos appels API sont sécurisés et fiables.

## Obtenir une clé API

Rendez-vous dans Console → API Tokens pour créer et gérer vos clés API.

<Callout client:load type="info" title="Étapes de création">
1. Connectez-vous à votre compte Aiberm
2. Accédez à la page Console
3. Cliquez sur « API Tokens » dans le menu de gauche
4. Cliquez sur le bouton « New Token »
5. Définissez le nom du jeton et les autorisations
6. Copiez la clé API générée
</Callout>

## Remarques de sécurité

- Conservez votre clé API en sécurité et ne l’exposez pas dans le code côté client
- Faites régulièrement tourner les clés API pour renforcer la sécurité du compte
- Si votre clé API fuit, supprimez-la immédiatement dans la console et générez-en une nouvelle
- Utilisez des variables d’environnement pour stocker les clés API plutôt que de les coder en dur

## Erreurs courantes

<Callout client:load type="error" title="401 Unauthorized">
Clé API invalide ou expirée

**Solution :** Vérifiez que la clé API est correcte, ou générez une nouvelle clé API
</Callout>

<Callout client:load type="error" title="403 Forbidden">
Autorisations insuffisantes ou compte restreint

**Solution :** Vérifiez l’état du compte et contactez l’administrateur pour obtenir les autorisations appropriées
</Callout>
