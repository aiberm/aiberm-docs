# Liste des modèles

Obtenez la liste de tous les modèles d’IA accessibles à l’utilisateur actuel, y compris les identifiants, les noms, les fournisseurs et les informations détaillées.

<Callout client:load type="info" title="À propos de la liste des modèles et des groupes de jetons">
Les modèles renvoyés dans la liste dépendent du groupe de jetons auquel appartient votre API KEY. Vous pouvez sélectionner le groupe de jetons lors de la création ou de la modification des jetons dans Console → API Tokens.
</Callout>

## Point de terminaison

`GET https://aiberm.com/v1/models`

## Champs de la réponse

**Champs de premier niveau :**
- `success` - Booléen, indique si la requête a réussi
- `data` - Tableau d’objets modèle (renvoyé uniquement en cas de succès)
- `message` - Message d’erreur (renvoyé uniquement en cas d’échec)

**Champs de l’objet modèle :**
- `id` - Identifiant unique du modèle
- `object` - Type d’objet, fixe à "model"
- `created` - Horodatage de création du modèle
- `owned_by` - Fournisseur du modèle (par ex. openai, anthropic)
- `supported_endpoint_types` - Tableau des types de points de terminaison API pris en charge

## Types de points de terminaison pris en charge

- `chat` - Complétion de chat
- `completion` - Complétion de texte
- `embedding` - Embedding de texte
- `image` - Génération d’images
- `audio` - Traitement audio
- `rerank` - Reclassement

## Remarques importantes

<Callout client:load type="info" title="Authentification requise">
Un jeton API valide doit être fourni. Le jeton détermine les modèles auxquels l’utilisateur peut accéder.
</Callout>

<Callout client:load type="info" title="Contrôle des autorisations">
La liste des modèles renvoyée est filtrée selon les groupes d’utilisateurs et les groupes de jetons, et n’affiche que les modèles auxquels l’utilisateur a le droit d’accéder.
</Callout>

## Erreurs courantes

- `401 Unauthorized` - Le jeton API est invalide ou expiré
- `403 Forbidden` - L’utilisateur n’a pas l’autorisation d’accès
- `500 Internal Server Error` - Erreur interne du serveur
