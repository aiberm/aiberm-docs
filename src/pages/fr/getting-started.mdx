# Démarrage rapide

Aiberm fournit une API unifiée qui vous donne accès à des centaines de modèles d’IA via un seul point de terminaison. Démarrez en quelques minutes grâce à une intégration simple.

<Callout client:load type="tip">
Vous cherchez des informations sur les modèles gratuits et les limites de débit ? Consultez la FAQ.
</Callout>

## Utiliser le SDK OpenAI

Le moyen le plus simple consiste à utiliser le SDK officiel OpenAI : il suffit de modifier le base_url pour commencer.

<CodeExample
  client:load
  examples={[
    {
      key: 'python',
      label: 'Python',
      code: `from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key-here",
    base_url="https://aiberm.com/v1"
)

response = client.chat.completions.create(
    model="google/gemini-2.5-flash",
    messages=[
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)`
    },
    {
      key: 'typescript',
      label: 'TypeScript',
      code: `import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: 'sk-your-api-key-here',
  baseURL: 'https://aiberm.com/v1'
});

const response = await openai.chat.completions.create({
  model: 'google/gemini-2.5-flash',
  messages: [
    { role: 'user', content: 'Hello!' }
  ]
});

console.log(response.choices[0].message.content);`
    }
  ]}
/>

## Utiliser l’API Aiberm directement

Vous pouvez appeler l’API directement via des requêtes HTTP.

<Callout client:load type="info">
Utilisez notre Request Builder interactif pour générer des requêtes API.
</Callout>

<CodeExample
  client:load
  examples={[
    {
      key: 'python',
      label: 'Python',
      code: `import requests

response = requests.post(
    "https://aiberm.com/v1/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={
        "model": "google/gemini-2.5-flash",
        "messages": [
            {"role": "user", "content": "Hello!"}
        ]
    }
)

print(response.json())`
    },
    {
      key: 'typescript',
      label: 'TypeScript',
      code: `const response = await fetch('https://aiberm.com/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    model: 'google/gemini-2.5-flash',
    messages: [{ role: 'user', content: 'Hello!' }]
  })
});

const data = await response.json();
console.log(data);`
    },
    {
      key: 'curl',
      label: 'Curl',
      code: `curl https://aiberm.com/v1/chat/completions \\
  -H "Content-Type: application/json" \\
  -H "Authorization: Bearer YOUR_API_KEY" \\
  -d '{
    "model": "google/gemini-2.5-flash",
    "messages": [
      {"role": "user", "content": "Hello!"}
    ]
  }'`
    }
  ]}
/>
