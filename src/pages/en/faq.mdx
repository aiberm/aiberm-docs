# FAQ

## What is the difference between the two sets of Claude models on Aiberm?

Aiberm offers two sets of Claude models for different use cases:

- **Models prefixed with `anthropic/`**: Routed through AWS, at a discounted price, with a fixed key, suitable for API calls.
- **Models prefixed with `claude-`**: Available at a 81% off discounted price. Can be used for both API calls and CLI tools (e.g., Claude Code). Claude Code supports `claude-` prefixed models by default.

## How do I get an Invoice?

- **Self-service Invoice**: [https://meiguo.app/invoice](https://meiguo.app/invoice)
- **Corporate bank transfer** invoices are available — please contact the group admin @Folyd
- **Non-corporate transfers** require a minimum of $500 for Chinese Fapiao. Below $500, an additional 8% tax surcharge applies.
