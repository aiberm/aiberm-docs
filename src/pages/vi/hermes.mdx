# Cài đặt Hermes Agent

Hướng dẫn này mô tả cách cấu hình [Hermes Agent](https://hermes-agent.nousresearch.com/) để dùng Aiberm làm nhà cung cấp mô hình. Hermes Agent là agent AI mã nguồn mở do Nous Research phát triển, chạy trong terminal và tích hợp với các nền tảng nhắn tin gồm Telegram, Discord, Slack, WhatsApp và Signal.

Vì Aiberm cung cấp API `/v1` tương thích OpenAI, bạn có thể đăng ký nó làm nhà cung cấp tùy chỉnh trong Hermes Agent mà không cần cài plugin hay sửa mã nguồn. Sau khi cấu hình, một API key cho phép bạn truy cập mọi mô hình có trên Aiberm, gồm Claude, GPT, Gemini, DeepSeek, Kimi, MiniMax, GLM và Grok.

## Điều kiện tiên quyết

- Một tài khoản Aiberm ([Đăng ký](https://aiberm.com/register))
- Một API key Aiberm ([Lấy khóa của bạn](https://aiberm.com/console/token))
- Đã cài Hermes Agent — xem [hướng dẫn cài đặt chính thức](https://hermes-agent.nousresearch.com/docs/getting-started/)

Cài nhanh (Linux / macOS / WSL2):

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

## Cấu hình Aiberm làm nhà cung cấp

Hermes Agent lưu cấu hình tại `~/.hermes/config.yaml`. Mở tệp và thêm mục `aiberm` trong phần `providers:`.

> **Nếu bạn không quen với trình soạn dòng lệnh như Vim**, bạn có thể mở tệp cấu hình bằng trình soạn tích hợp của hệ điều hành:
>
> - **macOS**: Mở **Finder**, nhấn `Shift + Command + G`, nhập `~/.hermes` trong hộp thoại hiện ra, rồi nhấn Return. Tìm tệp `config.yaml`, nhấp chuột phải và chọn **Open With → TextEdit**.
> - **Windows**: Mở **File Explorer**, gõ `%USERPROFILE%\.hermes` trên thanh địa chỉ, rồi nhấn Enter. Nhấp chuột phải `config.yaml` và chọn **Open with → Notepad**.
>
> Sau khi chỉnh, nhớ **lưu tệp** (`Command + S` trên macOS, `Ctrl + S` trên Windows), rồi tiếp tục bước khởi động lại mô tả bên dưới.

> **Mẹo**: Danh sách trên bao phủ phần lớn các mô hình Aiberm hiện cung cấp, khá dài. Chúng tôi khuyến nghị **chỉ giữ những mô hình bạn thực sự dùng** và xóa phần còn lại.

### Tham chiếu trường

| Trường | Bắt buộc | Mô tả |
|-------|----------|-------------|
| `base_url` | Có | Endpoint tương thích OpenAI của Aiberm. Đặt thành `https://aiberm.com/v1`. |
| `api_key` | Có | API key Aiberm của bạn, lấy từ [console](https://aiberm.com/console/token). |
| `type` | Có | Kiểu giao thức. Đặt thành `openai` — Aiberm tuân theo đặc tả OpenAI Chat Completions. |
| `default_model` | Có | Mô hình được dùng khi không chỉ định mô hình rõ ràng. |
| `models` | Khuyến nghị | Danh sách mô hình hiển thị trong bộ chọn `/model`. Hermes chỉ hiện các mục có trong danh sách này (cộng với `default_model`). Nếu bỏ qua, bộ chọn chỉ hiển thị một nút. |

Phần `model:` cấp cao nhất chỉ định nhà cung cấp đang dùng và mô hình mặc định. Nếu trước đó bạn dùng nhà cung cấp khác, hãy đặt `provider:` thành `aiberm` và đặt `default:` thành bất kỳ mô hình nào trong khối `models:`.

## Sử dụng

Sau khi cập nhật cấu hình, khởi động lại Hermes (CLI: thoát rồi chạy lại `hermes`; gateway: `hermes gateway restart`).

**Trong terminal (CLI):**

```
/model
```

Hermes mở bộ chọn mô hình tương tác. Chọn **Aiberm**, rồi chọn mô hình mong muốn. Bạn cũng có thể chuyển trực tiếp:

```
/model claude-opus-4-7
/model gpt-5.4 --global
```

Thêm `--global` sẽ lưu thay đổi vào `config.yaml`; bỏ qua thì thay đổi chỉ áp dụng cho phiên hiện tại.

**Trong Telegram, Discord, Slack hoặc WhatsApp:**

Gửi `/model` tới bot của bạn. Bot trả về bàn phím nội tuyến liệt kê mọi nhà cung cấp đã cấu hình thông tin xác thực. Chọn **Aiberm** để xem danh sách mô hình phân trang (8 mỗi trang, có điều hướng Prev / Next), rồi nhấn một mô hình để chuyển.

![Telegram /model picker showing Aiberm's paginated model list](/docs/hermes-model-picker.png)

## Xem danh mục mô hình đầy đủ

Danh sách `models:` ở trên là một tập hợp đã chọn lọc. Để xem mọi mô hình Aiberm đang phục vụ, truy vấn API trực tiếp:

```bash
curl -H "Authorization: Bearer sk-your-aiberm-api-key" \
     https://aiberm.com/v1/models | jq -r '.data[].id'
```

Thêm bất kỳ ID mô hình nào bạn muốn dùng vào khối `models:` rồi khởi động lại Hermes. Chúng sẽ xuất hiện trong bộ chọn `/model`.

## Dùng biến môi trường (Tùy chọn)

Nếu bạn không muốn lưu API key trong `config.yaml`, bạn có thể đọc từ biến môi trường. Đặt:

```bash
export AIBERM_API_KEY=sk-your-aiberm-api-key
```

Rồi tham chiếu trong `config.yaml` qua `key_env`:

```yaml
providers:
  aiberm:
    base_url: https://aiberm.com/v1
    key_env: AIBERM_API_KEY
    type: openai
    default_model: claude-sonnet-4-6
```

## Xử lý sự cố

### `/model` chỉ hiện một nút cho Aiberm

Khối `providers.aiberm` thiếu danh sách `models:`. Bộ chọn Hermes chỉ phân trang khi cấu hình hơn 8 mô hình. Thêm danh sách đã chọn lọc ở trên rồi khởi động lại Hermes.

### 401 Unauthorized

- Xác nhận API key tại [Aiberm console](https://aiberm.com/console/token).
- Xác nhận khóa được đặt dưới `providers.aiberm.api_key`, không phải ở cấp cao nhất của cấu hình.

### Không tìm thấy mô hình

Danh mục mô hình của Aiberm thay đổi theo thời gian; một mô hình bạn đã liệt kê có thể đã đổi tên hoặc bị ngừng. Truy vấn lại `/v1/models` (xem ở trên) và cập nhật danh sách `models:` cho phù hợp.

### Cách xác nhận cấu hình đã được tải

```bash
hermes doctor
```

Lệnh này in báo cáo chẩn đoán gồm nhà cung cấp và mô hình đang hoạt động.
