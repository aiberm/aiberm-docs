# Cài đặt Codex Desktop

Ứng dụng desktop OpenAI Codex có thể đăng nhập bằng API key và mở `config.toml` cấp người dùng từ trong ứng dụng. Khi đã cấu hình Aiberm, Codex gửi yêu cầu qua endpoint tương thích Responses của Aiberm.

<Callout client:load type="info">
Trường đăng nhập vẫn được gắn nhãn OpenAI API key. Hãy nhập API key Aiberm của bạn vào đó, ví dụ `sk-...`.
</Callout>

## Điều kiện tiên quyết

Trước khi bắt đầu, hãy đảm bảo bạn có:

- Ứng dụng desktop OpenAI Codex mới nhất
- Một tài khoản Aiberm ([Đăng ký](https://aiberm.com/register))
- Một API key Aiberm ([Tạo trong Console](https://aiberm.com/console/token))

## Cấu hình

1. Mở ứng dụng desktop Codex.
2. Trên màn hình đăng nhập, chọn **Sign in another way**.

![Choose another sign-in method in Codex Desktop](/docs/codex-desktop/codex-signin.png)

3. Nhập API key Aiberm vào trường **OpenAI API key**, rồi chọn **Continue**.

![Enter an API key in Codex Desktop](/docs/codex-desktop/codex-signin-with-apikey.png)

> Lưu ý: bước này chỉ giúp bạn vào ứng dụng desktop Codex. Bước này không thay thế cấu hình API key trong `config.toml`. Hãy hoàn tất cấu hình bên dưới ngay cả khi bạn đã nhập key trên màn hình đăng nhập.

4. Sau khi vào ứng dụng, mở Settings.
5. Chọn **Configuration** trên thanh bên.
6. Trong **Custom config.toml settings**, đảm bảo **User config** đã được chọn.
7. Chọn **Open config.toml** để mở tệp cấu hình cấp người dùng.

![Open config.toml in Codex Desktop](/docs/codex-desktop/codex-configuration.png)

8. Thêm hoặc thay nội dung `config.toml` bằng:

```toml
model = "gpt-5.6-sol"
model_provider = "aiberm"
model_reasoning_effort = "xhigh"

[model_providers.aiberm]
name = "Aiberm API"
base_url = "https://aiberm.org/v1"
experimental_bearer_token = "sk-your-aiberm-api-key"
wire_api = "responses"
supports_websockets = false
```

Thay `sk-your-aiberm-api-key` bằng API key Aiberm thật của bạn. Key được lưu dưới dạng văn bản thuần trên máy tính. Không commit tệp này vào Git và không chia sẻ tệp với người khác.

9. Lưu `config.toml`.
10. Thoát hoàn toàn rồi mở lại ứng dụng desktop Codex.

## Kiểm tra hoạt động

Sau khi mở lại Codex:

1. Mở một dự án hoặc workspace.
2. Yêu cầu Codex thực hiện một tác vụ lập trình thực tế, chẳng hạn giải thích tệp hiện tại, chỉnh một đoạn mã nhỏ, hoặc chạy kiểm thử dự án.

Nếu tác vụ chạy và trả về kết quả, cấu hình đang hoạt động.

## Xử lý sự cố

### API Key không hợp lệ

- Sao chép đầy đủ khóa từ [Aiberm Console](https://aiberm.com/console/token).
- Kiểm tra khoảng trắng thừa trước hoặc sau khóa.
- Xác nhận khóa bắt đầu bằng `sk-`.

### Thay đổi cấu hình không được áp dụng

- Xác nhận bạn đã chỉnh `config.toml` được mở từ **User config**.
- Thoát hoàn toàn rồi mở lại ứng dụng desktop Codex sau khi lưu tệp.
- Xác nhận `model_provider = "aiberm"` khớp với `[model_providers.aiberm]`.
- Xác nhận `experimental_bearer_token` đã được thay bằng API key Aiberm thật và placeholder không bị lưu nguyên trạng.

### Lỗi mô hình hoặc kết nối

- Xác nhận `base_url` chính xác là `https://aiberm.org/v1`.
- Xác nhận `wire_api` là `responses`.
- Xác nhận tài khoản của bạn truy cập được `gpt-5.6-sol`. Để xem danh sách hiện tại, xem [Danh sách mô hình](/docs/vi/models).
