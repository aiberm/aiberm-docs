# Skill Aiberm cho agent

[aiberm-skill](https://github.com/aiberm/aiberm-skill) dạy agent lập trình cách đọc tài khoản Aiberm của chính bạn. Sau khi cài, bạn có thể hỏi Claude Code, Codex hoặc agent khác: "Số dư Aiberm của tôi còn bao nhiêu?" Agent sẽ gọi API của Aiberm và trả lời bằng ngôn ngữ dễ hiểu.

Skill này đọc số dư, nhóm, mô hình, giá, API token, nhật ký sử dụng và lịch sử nạp tiền của bạn. Nó cũng có thể tạo, chỉnh sửa, kích hoạt, vô hiệu hóa và xóa API token của bạn, và luôn hỏi bạn trước mỗi thay đổi.

<Callout client:load type="info">
Skill là một thư mục chứa tệp `SKILL.md`. Khi câu hỏi của bạn khớp với mô tả của skill, agent đọc tệp đó rồi tự chạy `curl`. Không có gì chạy ngầm, cũng không có gì cần build hay giữ cho chạy liên tục.
</Callout>

## Điều kiện tiên quyết

- Một tài khoản Aiberm ([Đăng ký tại đây](https://aiberm.com/register))
- Một agent hỗ trợ skill, chẳng hạn [Claude Code](/docs/vi/claude-code/) hoặc [Codex](/docs/vi/codex/)
- `curl` và một shell tương thích bash. macOS và Linux đều có sẵn cả hai. Trên Windows, Claude Code dùng Git Bash.

## 1. Lấy ID người dùng và mã thông báo truy cập hệ thống

Skill cần hai giá trị, cả hai đều có trong [Cài đặt cá nhân](https://aiberm.com/console/personal):

| Giá trị | Vị trí |
| --- | --- |
| ID người dùng | Ở phần đầu trang, hiển thị dạng `ID: 123` |
| Mã thông báo truy cập hệ thống | Tab **Cài đặt bảo mật** → **Mã thông báo truy cập hệ thống** → **Tạo mã thông báo** |

Aiberm kiểm tra cả hai giá trị ở mọi yêu cầu liên quan đến tài khoản, và ID phải thuộc về tài khoản sở hữu token.

<Callout client:load type="warning">
Mã thông báo truy cập hệ thống **không phải** là API key (`sk-...`). Nó có tác dụng như phiên đăng nhập console của bạn: ai có nó đều làm được mọi việc bạn làm được trong console. Hãy giữ kín token này. Nhấn **Tạo lại** sẽ thay token cũ, và mọi nơi còn dùng token cũ sẽ ngừng hoạt động.
</Callout>

## 2. Cài skill

Sao chép thư mục `skills/aiberm` trong repository vào thư mục skill của agent:

```bash
git clone https://github.com/aiberm/aiberm-skill.git
mkdir -p ~/.claude/skills
cp -R aiberm-skill/skills/aiberm ~/.claude/skills/aiberm
```

| Agent | Thư mục skill |
| --- | --- |
| Claude Code | `~/.claude/skills/aiberm` cho mọi dự án, hoặc `.claude/skills/aiberm` bên trong một dự án |
| Codex | `~/.codex/skills/aiberm` |
| Cursor | `~/.cursor/skills/aiberm` |

Với các agent khác, hãy đặt thư mục `aiberm` vào nơi agent tải skill. Để cập nhật sau này, chạy `git pull` trong bản clone rồi sao chép lại thư mục.

## 3. Đặt hai biến môi trường

Agent đọc các giá trị từ môi trường của nó, nên hãy đặt chúng trước khi khởi động agent.

**macOS / Linux**: thêm các dòng sau vào `~/.zshrc` hoặc `~/.bashrc`, rồi mở terminal mới:

```bash
export AIBERM_ACCESS_TOKEN="your-system-access-token"
export AIBERM_USER_ID="123"
```

**Windows (PowerShell)**: chạy các lệnh bên dưới, rồi mở terminal mới:

```powershell
setx AIBERM_ACCESS_TOKEN "your-system-access-token"
setx AIBERM_USER_ID "123"
```

<Callout client:load type="tip">
Riêng với Claude Code, bạn cũng có thể đặt cả hai biến trong khối `env` của `~/.claude/settings.json`.
</Callout>

Để kiểm tra các giá trị trước khi dùng agent, hãy gửi yêu cầu lấy hồ sơ của bạn. `data.quota` chia cho 500000 là số dư còn lại tính bằng USD.

```bash
curl -sS "https://aiberm.com/api/user/self" \
  -H "Authorization: Bearer $AIBERM_ACCESS_TOKEN" \
  -H "New-Api-User: $AIBERM_USER_ID"
```

## 4. Hỏi agent

Bắt đầu một phiên agent mới và hỏi theo cách của bạn:

- "Số dư Aiberm của tôi còn bao nhiêu?"
- "Hôm qua tôi tiêu bao nhiêu trên Aiberm, chia theo từng mô hình?"
- "Liệt kê các API token Aiberm của tôi và hạn mức còn lại của từng token."
- "Trong nhóm của tôi, `claude-sonnet-5-5` giá bao nhiêu cho 1 triệu token?"
- "Tuần này tôi dùng mô hình nào nhiều nhất trên Aiberm?"
- "Cho tôi xem các lần nạp tiền gần đây trên Aiberm."
- "Tạo một API key Aiberm tên `my-app` với hạn mức $5."
- "Vô hiệu hóa token Aiberm `old-test` của tôi."

Trong Claude Code, bạn cũng có thể gọi skill trực tiếp bằng `/aiberm`.

| Bạn hỏi về | Skill đọc |
| --- | --- |
| Số dư và tổng chi tiêu | `GET /api/user/self` |
| Nhóm và tỷ lệ giá của từng nhóm | `GET /api/user/self/groups` |
| Mô hình bạn có thể gọi | `GET /api/user/models` |
| Giá mô hình | `GET /api/pricing` |
| API token | `GET /api/token/` |
| Nhật ký sử dụng | `GET /api/log/self` |
| Tổng mức sử dụng | `GET /api/log/self/stat` |
| Mức sử dụng theo giờ và theo mô hình | `GET /api/data/self` |
| Lịch sử nạp tiền | `GET /api/user/topup/self` |
| Tạo, chỉnh sửa hoặc xóa API token | `POST`, `PUT` hoặc `DELETE /api/token/` |

Số tiền được quy đổi sang USD theo tỷ lệ 500000 đơn vị hạn mức = $1. Giá được tính theo tỷ lệ của các nhóm trên tài khoản của bạn, không theo mức mặc định công khai.

### Tạo và thay đổi API token

- Trước mỗi lần tạo, chỉnh sửa, kích hoạt, vô hiệu hóa hoặc xóa, agent cho bạn biết nó sẽ gửi gì và chờ bạn đồng ý.
- Trừ khi bạn yêu cầu khác, token mới có hạn mức không giới hạn và không hết hạn, giống như trong console. Bạn có thể yêu cầu hạn mức chi tiêu, ngày hết hạn, nhóm hoặc danh sách mô hình được phép.
- Sau khi tạo token, agent hiển thị khóa đầy đủ của nó một lần. Hãy sao chép khóa vào ứng dụng hoặc cấu hình của bạn.
- Xóa token là không thể hoàn tác, và các ứng dụng dùng khóa của token đó sẽ ngừng hoạt động ngay lập tức.

## Những việc skill không làm

- Ngoài API token, skill không thay đổi bất cứ thứ gì. Nó không thanh toán, không đổi mã nạp tiền và không chỉnh sửa tài khoản của bạn. Hãy dùng [console](https://aiberm.com/console) cho những việc đó.
- Skill không đặt lại mã thông báo truy cập hệ thống của bạn. Skill yêu cầu agent không bao giờ gọi endpoint đó.
- Skill không để lộ khóa đầy đủ của các API token hiện có. Danh sách token chứa khóa đầy đủ, nhưng agent chỉ hiển thị dạng đã che, như `sk-abcd****wxyz`. Hãy sao chép khóa đầy đủ từ [Quản lý mã thông báo](https://aiberm.com/console/token). Ngoại lệ duy nhất là token mà agent vừa tạo cho bạn.

<Callout client:load type="warning">
Các quy tắc này là chỉ dẫn cho agent, không phải cơ chế khóa kỹ thuật. Token này cho phép mọi việc mà phiên đăng nhập console của bạn cho phép. Chỉ dùng nó với agent và máy bạn tin tưởng. Nếu token bị lộ, hãy nhấn **Tạo lại** trong Cài đặt cá nhân.
</Callout>

## Xử lý sự cố

| Bạn thấy gì | Việc cần làm |
| --- | --- |
| Agent báo thiếu biến môi trường | Đặt cả hai biến, mở terminal mới và bắt đầu phiên agent mới. |
| `未提供 New-Api-User` | Chưa đặt `AIBERM_USER_ID`. |
| `New-Api-User 与登录用户不匹配` | `AIBERM_USER_ID` không phải ID của tài khoản sở hữu token. Hãy sao chép ID từ Cài đặt cá nhân của chính tài khoản đó. |
| `access token 无效` | Token sai hoặc đã được tạo lại. Hãy tạo token mới và cập nhật `AIBERM_ACCESS_TOKEN`. |
| Agent không dùng skill | Kiểm tra tệp nằm ở `~/.claude/skills/aiberm/SKILL.md` (hoặc thư mục của agent bạn dùng) rồi bắt đầu phiên mới. Trong Claude Code, gõ `/aiberm`. |
| `时间跨度不能超过 1 个月` | Mức sử dụng theo giờ chỉ lấy được tối đa 30 ngày cho mỗi yêu cầu. Hãy hỏi khoảng thời gian ngắn hơn. |

Mã nguồn của skill và danh sách đầy đủ các yêu cầu có trong [repository aiberm-skill](https://github.com/aiberm/aiberm-skill). Với lỗi từ chính API mô hình, xem [Xử lý lỗi](/docs/vi/error-handling/).
