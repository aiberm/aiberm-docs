# Câu hỏi thường gặp

## Sự khác biệt giữa hai nhóm mô hình Claude trên Aiberm là gì?

Aiberm cung cấp hai nhóm mô hình Claude cho các trường hợp sử dụng khác nhau:

- **Các mô hình có tiền tố `claude-`**: Có mức giá giảm 81%, phù hợp nhất cho kịch bản lập trình. Claude Code hỗ trợ các mô hình tiền tố `claude-` theo mặc định.
- **Các mô hình có tiền tố `anthropic/`**: Được định tuyến qua AWS, giảm khoảng 28% so với giá chính thức.

## Các mô hình Aiberm có hỗ trợ caching không?

Có, tất cả mô hình Claude trên Aiberm đều hỗ trợ prompt caching. Caching đã được tối ưu để đạt tỷ lệ hit cao. Khi cache hit, giá được nhân với 0.1. Các mô hình khác cũng hỗ trợ caching.
